## What this does

The policy T03 wrote becomes enforced in two places. Locally, `pre-commit install` once per
clone makes every commit run gitleaks, the hygiene hooks and ruff (`ruff-check --fix` so
trivial findings are fixed in place, `ruff-format` so the tree stays formatted). Remotely,
every push and PR to `main` runs the engine suite (2030 tests) and the ruff gates on Linux,
and the desktop suite (tsc + svelte-check + vitest + Biome) on node 22 — the first time this
repository's tests run anywhere but the dev Mac. The behaviour oracle (T01) runs inside the
engine job; nothing in it is macOS-specific by construction, so a red oracle there is a real
finding. The task is done when the workflow has run green on `origin/main` (watched with
`gh run watch`); a red run is a defect fixed inside this task, not a note.

Success: pre-commit (or the two ruff commands) exit 0 locally; the `ci.yml` run on `origin/main` finishes with both jobs green. Failure: re-read plan, check if spec drifted.
