## What this does

The Svelte panel built in T01–T03 as a second page becomes the one panel. `main.ts` already loads `index.html` (dev server and `loadFile`), so the swap is the HTML body plus deletions — no main-process change. `index.css` keeps only what Cockpit and Atlas still need (they die in S05-T02 together with the file); the old panel's selectors (`.vault`, `.health`, `.add-card`, `.nav-hint`, `.listener-row`, `.disclosure`, `.advanced-actions`, `.footer`, …) are removed after the consumer grep, so the file reads as "cockpit + atlas styles" afterwards. The harness captures `index` with every state the Svelte panel supports and fails the run when (a) any strict-page text overlaps / clips / leaves the viewport (existing gate) or (b) the fresh panel requests more than 640 px — the number the operator's screen enforces via `PANEL_MAX_H`. `npm run package` proves the Forge production bundle builds with the new entry (the `.vite/build/main.cjs` + renderer bundle path is what the DMG ships).
