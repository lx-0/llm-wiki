## What this does

New `Personal.watched_folders: list[dict]`, each entry shaped:

```yaml
watched_folders:
  - id: docs-private          # stable handle, used by the index + requests later
    kind: local               # local | smb
    path: ~/Sync/Private/Documents   # local roots use `path`
    include: ["**/*"]         # optional globs (default: all)
    exclude: ["**/.git/**"]   # optional
  - id: nas-multimedia
    kind: smb                 # smb roots use `share` (+ host via env/creds later)
    share: Multimedia
```

Default `[]`. `_validate_watched_folders_schema(personal_raw)`:
- each entry must have a non-empty `id` and `kind in {"local", "smb"}`
- `kind: local` requires `path`; `kind: smb` requires `share`
- unknown `kind` / missing required field -> raise a clear config error naming
  the offending entry id (mirror the `_validate_accounts_schema` message style:
  collect all offenders, raise once).

Validation only -- no filesystem/SMB access, no scanning, no index. The
migration writes `personal.watched_folders: []` into operator vaults on
`wiki update` so the key is present (dataclass-default fall-through is not
enough per the config-knob rule).
