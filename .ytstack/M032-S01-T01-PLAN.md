# M032-S01-T01 -- Task Plan

**Summary:** Render harness in-repo: standalone renderer build, a stub preload serving `window.{vault,listeners,panel,app}` from fixtures, an Electron capture script (offscreen windows, light + dark, per-surface and per-panel-state `capturePage()`, requested panel height logged) → `npm run shots` writes `desktop/out/shots/*.png` + `report.json`.

## Files

- Create: `desktop/scripts/shots/fixtures.cjs` — `build(state)` → the four API payloads for a named state (`default`, `running`, `failed`, `no-access`, `empty`), timestamps relative to now.
- Create: `desktop/scripts/shots/stub-preload.cjs` — reads `--shots-state=<name>` from `process.argv` (`webPreferences.additionalArguments`), exposes the four domain APIs via `contextBridge` from the fixtures, records registered callbacks + requested panel heights, exposes `window.__shots = { heights(), fire(event, payload) }` for the capture script.
- Create: `desktop/scripts/shots/capture.cjs` — Electron main script: `force-device-scale-factor=2`, `app.dock.hide()`, for each surface × scheme × state: in-memory `partition`, `nativeTheme.themeSource`, offscreen `BrowserWindow` sized like `main.ts`, `loadFile(.vite/renderer/main_window/<page>.html)`, settle, optional state script (`asked` types a question; `expanded` opens Health/Sources/Advanced; `failed` fires `compileDone {ok:false}`), panel resized to its requested height before capture, `capturePage().toPNG()` → `out/shots/<page>-<scheme>-<state>.png`; writes `out/shots/report.json` (panel heights per state, console errors per page); exits non-zero on page errors.
- Modify: `desktop/vite.renderer.config.ts` — add `base: './'` + `build.outDir: '.vite/renderer/main_window'` (Forge's own defaults from `plugin-vite/dist/config/vite.renderer.config.js`) so `vite build -c vite.renderer.config.ts` is byte-equivalent to the Forge renderer build.
- Modify: `desktop/package.json` — scripts `build:renderer` and `shots`.

## What this does

`npm run shots` = `vite build -c vite.renderer.config.ts && electron scripts/shots/capture.cjs`.
The capture script iterates the surface table:

```
index.html      360 × fit   light+dark   states: fresh, asked, expanded, running, failed, no-access, empty
onboarding.html 460 × 700   light+dark   default
settings.html   400 × 400   light+dark   default
browse.html     480 × 620   light+dark   default, empty
triage.html     720 × 760   light+dark   default, empty
cockpit.html   1040 × 700   dark         default   (deleted in S05 — table shrinks then)
atlas.html     1100 × 720   dark         default
```

Each window gets `webPreferences: { preload: stub-preload.cjs, sandbox: false, offscreen: true,
additionalArguments: ['--shots-state=<state>'], partition: '<unique>' }`; the panel window gets a
solid `backgroundColor` per scheme because offscreen rendering has no vibrancy. After
`did-finish-load` + 1.2 s (3.5 s for the canvas pages) the state script runs via
`executeJavaScript`, then for the panel the last value of `window.__shots.heights()` becomes the
window height (so the PNG shows the whole requested content and the number lands in the report
— the ≤ 640 exit criterion is checked against that number, not by clipping). `pageerror` /
`console-message` (error level) are collected per page; any entry fails the run (exit 1) so the
harness doubles as a smoke test of the built bundle.

Fixtures are plain objects (no generators needed): a 42-entry `list()` across the 8 type
folders with mtimes from 12 min to 120 d, `status()` with `recent` = first five, a 3-issue
doctor with `updateAvailable`, a 5-suggestion menu across groups do/review/auto, 9 collectors
(one unconfigured), a 6-record triage (one accepted), one running screenpipe listener;
`running` adds `compileStatus.running` 3/12 + `runStatus.running='compile'`; `failed` is
`default` + a fired `compileDone {ok:false, durationMs: 41000}`; `no-access` flips
`accessible=false`; `empty` zeroes everything and stops the listener.
