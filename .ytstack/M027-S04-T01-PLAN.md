## What this does

**Contract (the seam — Q9 closed):**

```
@dataclass ScanAnswer:
    answer_md: str          # distilled, topic-focused markdown — NEVER the raw body
    file_path: str          # rel_path answered from
    as_of_mtime: float      # stat'd at read time (staleness carry for T02/T03)
    input_tokens: int; output_tokens: int
    error: str | None       # provider-level failure (None = success)

class FolderScanProvider(Protocol):
    async def answer(self, *, topic: str, rationale: str,
                     file_abs: Path, file_rel: str) -> ScanAnswer

def get_provider() -> FolderScanProvider
    # CONFIG.models.folder_scan_provider == "claude-sdk" -> ClaudeSdkProvider()
    # anything else -> raise ConfigError (LOUD; no silent fallback —
    # feedback_no_silent_provider_fallback). Registry dict so a local
    # provider is a one-entry addition later.
```

**ClaudeSdkProvider.answer()** — `compile_source` is the template
(StderrCapture + log_sdk_failure + per-call timeout discipline from
`core.sdk_helpers`):

- stat the file first → `as_of_mtime` (FileNotFoundError propagates to
  the caller; quarantine semantics are T03's).
- `ClaudeAgentOptions`: `cwd=str(file_abs.parent)`,
  `allowed_tools=["Read"]` ONLY (no Write/Edit/Glob/Grep — the agent
  reads exactly one named file; the backend persists in Python, T02),
  `PreToolUse` `HookMatcher(matcher="Read",
  hooks=[make_path_scope_hook([file_abs])])` — file-as-root exact-path
  scope (operations-log precedent), `permission_mode="default"`,
  `max_turns` small (≈6), `model` = `CONFIG.models.compile_model` for
  now (provider-internal choice, not a knob until needed),
  `system_prompt=render("folder_scan_answer_system")`.
- user prompt `render("folder_scan_answer", topic=…, rationale=…,
  file_rel=…, file_abs=…)`: read THIS file, extract ONLY what answers
  the topic; explicit ban on reproducing the document wholesale
  (answer-extract, the P2 contract — full enforcement test lands in T02).
- collect ResultMessage → `ScanAnswer` (empty/None result →
  `error="empty_result"`); usage counters cache-aware NOT needed here
  yet (single call, total_cost in ResultMessage — note for T02 ledger).

**Prompts** (`prompts/`, never inline): system = role + answer-extract
contract + "you may be reading personal documents — extract facts, do not
moralize"; user = topic/rationale/file + output shape (markdown answer,
"NOT ANSWERED IN THIS FILE" sentinel when the file doesn't contain it —
T02 persists, T03 uses the sentinel).

Tests (~5, SDK mocked at `folder_providers.query`):

1. `get_provider()` returns the Claude provider on default config.
2. unknown provider name → ConfigError (loud, no fallback).
3. `answer()` happy path: mocked query yields a ResultMessage → ScanAnswer
   with answer_md + as_of_mtime == file's stat; captured
   `ClaudeAgentOptions` assert `allowed_tools == ["Read"]` AND a
   PreToolUse hook is present (the path-scope wiring is load-bearing).
4. missing file → FileNotFoundError propagates (T03 will catch).
5. empty SDK result → `error="empty_result"`, no exception.
