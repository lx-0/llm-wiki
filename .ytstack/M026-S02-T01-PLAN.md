## What this does

Move into `route.py` (verbatim bodies; `_DEFAULT_DISPATCH` needs `from core.config import CONFIG`):
`SUBSTRATE_PROMPTS`, `_DEFAULT_DISPATCH`, `_SUBSTRATE_PATH_FALLBACKS`, `_substrate_key`,

`decide_route(source, content, *, force=False) → Route` reproduces compile_file's
pre-LLM decision IN ORDER, pure (no logging/IO/state):
1. empty body → `Skip("empty")`
2. `infer_compile_role`; `final-only` → `Skip("compile_role_final_only")`;
   `source-and-final` → `IndexOnly(title, tuple(extract_wikilinks(content)))`
3. skip-list: `not force and type in CONFIG.limits.compile_skip_substrate_types`
   → `Skip(f"substrate_type_excluded_{type}")`
4. `type == "health-rollup" and _health_rollup_body_is_stub(content)` → `HealthStub()`
5. else `Compile(metadata, classify(content, source))` where metadata =
   `CompileMetadata(source_path=source, compile_role=…, model_id=<precedence>,
   max_turns=<precedence>, substrate_type=type, substrate_prompt=<dispatch>,
   project_slug=None, project_page_rel=None)`.

Model precedence (verbatim from compile.py:604-628): `substrate_model` wins → else
force-long-context (`type in compile_force_long_context_types` and a large-source model
set) → else size-escalation (`len(content) >= compile_large_source_chars`) → else
`CONFIG.models.compile_model`. max_turns (638-643): `substrate_max_turns` → force-long
→ `compile_max_turns`.

`route.py` imports (no cycle — none import `route`): `core.config.CONFIG`,
`core.paths.ROOT_DIR`, `core.compile_role.infer_compile_role`,
`core.utils.extract_wikilinks`, `.classify.classify`, `.types.CompileMetadata`.
