## What this does

Template variables (fixed by T01): `${source_path}`, `${source_content}`,
`${folder_digests}`, `${timestamp}`.

Structure mirrors `compile_curiosity.md`, adapted to the folder pass:

- Role: gap detector over a newly-compiled source; candidate answers are
  FILES in the operator's watched folders, visible ONLY as a body-blind
  metadata index (names/dates/sizes — never content).
- Authority clause: gaps derive solely from the source; file picks derive
  solely from the digest listing below — no invented paths.
- JSON contract (exactly the T01 schema): gaps[] of `topic`, `root_id`
  (frontmatter `root_id:` of the digest the file belongs to), `file_path`
  (copied VERBATIM from a backticked path in the digest — validated
  server-side, invented paths are dropped, no exceptions), 
  `file_confidence` (1-5 scale adapted: 5 = filename/folder names the
  topic exactly … 1 = filling the slot; below-threshold dropped
  server-side), `rationale` (why THIS file plausibly answers it).
- Folder-specific honesty rules: you see ONLY metadata — judge by
  filename/folder/date/size, never claim knowledge of content; prefer
  specific named documents over generic ones; created/modified dates are
  triage signal (recent ≠ relevant); empty array is valid and preferred;
  no padding to 3.
- `${folder_digests}` block at the end + timestamp cache-buster.

Test (1): render the real template with sample kwargs → contains the
sample path, the JSON field names (`root_id`, `file_path`,
`file_confidence`), the digest block, and no unsubstituted `${`.
