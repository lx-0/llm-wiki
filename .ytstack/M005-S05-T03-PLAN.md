## What this does

The dashboard pane (T01) shows operator-facing summary slices (Overdue / Today / This Week). The Inbox MOC is the **canonical landing page** for the full task inventory:

- One section per entity-type folder (People / Projects) showing all open `- [ ]` items in that folder, grouped by file
- An aggregate "All overdue", "All due this week", "All without due date" view spanning both folders
- A short header explaining the lifecycle: items come from compile-time extraction (jamie/gmeet/email substrates), persist in entity-page State blocks, move to Timeline when resolved (per M005-S04 rules)

The MOC carries `type: moc` so it appears in the dashboard's `## 🗂 MOCs` listing too — operator can navigate either way.
