# M034-S03-T03 -- Task Plan

**Summary:** One backup helper, `scripts/core/backup.py`, with T02's rule: a backup never
lands on an earlier one, and a clash takes `-2`, `-3`, …. Release 0.7.17.

A repo-wide grep found the to-the-second overwrite flaw that T02 fixed in the bash in five
Python writers. Two backups in one second share a name, and the second replaces the first,
which is the pre-change original:

| writer | name | reachable |
| --- | --- | --- |
| `core/frontmatter.backup` (correct, take, correct_apply) | `<name>.bak.<ts>` | hardly: one backup per SDK-bound run |
| `dedup.py` (hand-rolled) | `<name>.bak.<ts>` | hardly |
| `adapters/mailbox/thunderbird._backup` | `<name>.backup-<ts>` | **yes**: a batch of filter rules writes the same file within milliseconds |
| `adapters/mailbox/allinkl._backup` | `raw/notes/email/procmail-backup-<account>-<ts>.txt` | **yes**: the same, per account |
| `optimize_claude_md.py` | `<backup dir>/CLAUDE.md.backup-<ts>` | hardly |

`core/config_backup.py` already avoids the clash (microseconds, a clash rule from S02) and
stays as it is.

## Files

- **Create `scripts/core/backup.py`** with three functions:
  - `stamp()` — the compact `YYYYmmdd-HHMMSS`;
  - `backup_path(directory, stem, ext="")` — `<stem><stamp>[-n]<ext>`, the first name not
    taken;
  - `backup(path)` — the sibling copy `<name>.bak.<stamp>[-n]` (the bash's form), or
    `None` when the path is missing.
- **Modify the callers.** Every file name stays as it is, so nothing an operator might look
  for moves.
  - `facts/correct.py`, `facts/take.py`, `facts/correct_apply.py` and `dedup.py` call
    `backup()`. Remove `core/frontmatter.backup` (no soft deprecation).
  - `adapters/mailbox/thunderbird.py`, `adapters/mailbox/allinkl.py` and
    `optimize_claude_md.py` call `backup_path()`.
  - `correct_apply.py`'s `.trash/<stamp>` dir uses `stamp()`.
- **Create `tests/test_backup.py`**, written RED first:
  - two backups in one second keep both, the first byte for byte (date pinned);
  - a missing path gives `None`;
  - `backup_path` adds `-2` before `ext`;
  - a seam guard: `"%Y%m%d-%H%M%S"` appears in `scripts/` only in `core/backup.py`. One
    exception, named in the test: `agent_task.py`'s log-file name, which is not a backup.
    Its pattern must match the five writers above before they move.

  The `frontmatter` backup tests move from `tests/test_frontmatter.py` to here.
- **Modify `docs/engine-layout.md`:** `backup.py` in the core tree and a seam row.
- **Modify `CHANGELOG.md`, `pyproject.toml`, `uv.lock`** (0.7.17).
