## What this does

Scaffold a minimal Electron app and prove it neither breaks nor is touched by the
Python toolchain.

- **Framework tool — RECOMMENDED `electron-forge` + Vite + TypeScript template**
  (`npm init electron-app@latest desktop -- --template=vite-typescript`): official,
  integrated build/package/make, and its makers cover the macOS **signing +
  notarization + auto-update** needed in S03. Alternative: `electron-vite` +
  `electron-builder`. **Research gate (project rule):** before running the
  scaffolder, confirm the current scaffold command AND that the chosen tool's
  macOS sign/notarize/auto-update support is adequate, via official docs
  (context7 / WebSearch). Lock the choice in `M029-CONTEXT.md` open-questions.
- Minimal `main` opens a single `BrowserWindow`; renderer shows a static
  placeholder ("llm-wiki — connecting…"). No IPC, no `wiki`/`launchctl` calls.
- **Toolchain isolation:** `desktop/` carries its own `package.json` + (gitignored)
  `node_modules`. pytest (`testpaths=["tests"]`) and ruff (`.py`) already exclude
  it; the only repo-level CI is `secrets-scan.yml` (unaffected — node_modules
  ignored). The Python pipeline of the parallel milestones must stay green.
