## What this does

The Overview gets its four remaining cells and becomes the window that replaces Cockpit + Atlas. Each chart follows the form its data asks for: **type distribution** is magnitude across nominal categories → horizontal bars in one hue with the type badge carrying identity (the badge is the product's type colour everywhere; the bar does not re-encode it) and every value labelled, so no axis; **capture** is magnitude on a time × channel grid → a heat strip in one hue, four lightness steps from a validated ordinal ramp, the empty track for "nothing", a scale legend; **health** is a status figure, not a chart → the ring and the doctor rows with the engine's verbs (same vocabulary as the panel, same run-state semantics); **next up** is the panel's merged action list with more room. The table toggle gives every chart its WCAG-clean twin — the one control sits in the header row, scopes everything below, and never changes the data. Tooltips enhance; the table and the direct labels carry the values without them.
