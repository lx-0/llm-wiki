## What this does

The negation branch flips to **supersede**: annotate the article (`status:
superseded` + `superseded_by:` + `outdated_since:` + a `> [Superseded …]` banner
under the H1), keep the body, verbatim rule "outdated != false — annotate, never
delete history." The agent has Write/Edit only (no shell): it annotates directly,
but proposes renames/deletions in the JSON block for the engine to execute.

Contract (`## Proposed actions`, fenced ```json, jsonrepair-parsed by T04/T05/S02):
```json
{"superseded": [...], "edited": [...],
 "renamed": [{"from": "...", "to": "..."}], "deleted": []}
```
`${deletion_allowed}` = "false" in S01 → the prompt instructs: never nominate
deletions, always supersede. Disambiguation renames go through `renamed` (engine
moves + rewrites wikilinks in T04); clarification edits in place.
