## What this does

Operator-facing docs explaining: cache file lives at vault root next to `_dashboard-stats.md`, refreshed by the same trigger flow (`wiki flush` post-`refresh_dashboard_stats`, plus `wiki lint` / `wiki seed` / `wiki compile` / `wiki correct` per S02-T03). Four queues map to:

- **Orphans** — articles in `knowledge/` that no other article links to (lint.check_orphan_pages)
- **Stale** — articles whose source has changed since last compile (lint.check_stale_articles)
- **Missing backlinks** — articles linking to other articles that don't link back (lint.check_missing_backlinks)
- **Failed flushes** — markdown stubs left in `.wiki/sessions/failed-flushes/` when a flush crashed mid-pipeline

Each Dashboard callout uses `[!warning]-` (collapsed) when count > 0, `[!success]` when count == 0. Click any wikilink in an expanded callout to jump to the offending file.
