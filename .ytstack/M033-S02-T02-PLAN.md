## What this does

Three real modules get importable names; two shims disappear because the modules they
wrapped are runnable themselves (today by file path with their own bootstrap, after T03 as
`python -m preprocessors.inbox` / `preprocessors.html_ingest`). `cli.py` and the piggyback
table point at the new paths, so `wiki process-inbox`, `wiki ingest-html`, `wiki
review-wiki` and the three piggybacks behave exactly as before — proven by the suite, the
oracle (the help catalogue is unchanged: command names did not move), a `--help` run of
each renamed script and of both preprocessors by path, and `wiki`'s bash `_run_script`
paths (none name these files). Every mention in docs and comments follows in the same
commit; `git grep` for the old names afterwards finds only history (CHANGELOG, `.ytstack`)
and the diagram labels deferred to S05-T05.
