## What this does

`compile_file` keeps: per-file header log, dry-run early-return, read-content. Then:

```python
route = decide_route(source, source_content, force=force)
if isinstance(route, Skip):      # per-reason log → {"_skipped": reason}
if isinstance(route, IndexOnly): # index-write + state → {"_skipped": "...source_and_final_indexed"}
if isinstance(route, HealthStub):# deterministic record + state → {"_skipped": "...stub_deterministic"}
# else Compile: dispatch log; memory pre-pass enriches metadata; chunk/single compile_source
```

The decision logic (compile_role inference, skip-list, dispatch precedence, classify)
now lives in `decide_route` — `compile_file` no longer recomputes it, only executes.
