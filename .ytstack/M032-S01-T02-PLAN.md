## What this does

Toolchain matrix settled 2026-10-14 (versions verified against npm): TypeScript 5.9.3 (svelte-check
4.7 peers TS ^5||^6; TS 7 is the Go port — not for this stack yet), later tasks bring Electron
Forge 8.0.1 + Vite 8.3.4 + Svelte 5.57 + vite-plugin-svelte 7.3 + Biome 2.5.15. This task only
moves TypeScript and makes the compiler a real gate again: `tsc --noEmit` currently reports 866
errors inside `node_modules` because TS 4.5 cannot parse modern `.d.ts` syntax, so there has been
no typecheck at all. After the upgrade, `tsc` runs over `src/` + the root `*.ts` configs with
`strict`; errors are fixed at the call site (narrowing, explicit types), never with `any` or
`!` where a guard reads naturally. `moduleResolution: bundler` matches Vite's resolution and is
what Forge 8's template uses.
