## What this does

```python
def _is_final_only(article: Path) -> bool:
    """True iff the article's frontmatter has `compile_role: final-only`."""
    try:
        text = article.read_text(encoding="utf-8")
    except OSError:
        return False
    if not text.startswith("---"):
        return False
    end = text.find("\n---", 3)
    if end == -1:
        return False
    block = text[3:end]
    return bool(re.search(r"^compile_role:\s*[\"']?final-only[\"']?\s*$", block, re.MULTILINE))
```

Usage:
- `articles_total = len([a for a in list_wiki_articles() if not _is_final_only(a)])`
- `articles_final_only = sum(1 for a in list_wiki_articles() if _is_final_only(a))`
- In `_open_action_items_in_entities`: skip entity if `_is_final_only(article)`
