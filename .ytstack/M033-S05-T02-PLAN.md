## What this does

runtime. The one runtime edit is the `getattr` label, which is identical for functions. The
oracle goldens prove it: `doctor --quick --json` serialises `health.to_json`, and
`menu --json` serialises the action payloads.

The fix is local. No `Any` is added. A suppression is used only for an untyped dependency and
names ty's rule (`# ty: ignore[rule]`), with the reason beside it. Per KNOWLEDGE, no foreign
codes.
