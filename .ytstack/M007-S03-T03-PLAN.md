## What this does

Instead of programmatic index filtering (would require per-row frontmatter reads, expensive at vault size), append a prompt-context paragraph to `facts_md`:

- Default (flag absent): "SKIP articles with `compile_role: final-only` — they're archived hand-curated. Mention only if no non-archived material answers the question."

This trusts the LLM to honor the rule (visible to it as part of facts_md context, which is treated authoritative). Source-only and source-and-final remain in scope by default.
