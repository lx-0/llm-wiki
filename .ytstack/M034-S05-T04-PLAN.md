# M034-S05-T04 -- Task Plan

**Summary:** One help system. Every help text is in `cli_help`, and since T03 none is left
in the bash. This task renders them from one place and pins both facts with tests. `wiki
help <cmd>` prints that command's help, which today it ignores in favour of the whole
catalogue.

## Files

- Modify: `scripts/cli_help.py`.
  - `print_help(text)`: the dispatcher's `_style_help` moved here. It prints bold title +
    ALL-CAPS headers when stdout is a terminal (judged at call time) and plain text
    otherwise.
- Modify: `scripts/cli.py`.
  - `_print_help_text` and the catalogue's styling go through `print_help`.
  - `help <cmd>` prints `<cmd>`'s help, an alias's target included. An unknown name is the
    dispatcher's "unknown command" error, exit 1.
- Modify: the five handlers that print a help text themselves: `config_cli.py`,
  `hooks_cli.py`, `skills_cli.py`, `seed_cli.py`, `update_cli.py` (`print(H_X)` →
  `print_help(H_X)`). On a terminal their help is styled like `wiki <cmd> -h`; piped, it is
  unchanged.
- Modify: `tests/test_cli.py`.
  - `wiki help <cmd>` and the unknown name.
  - A seam guard: no `print(H_` under `scripts/`.
  - A bash guard: no heredoc or `help_*` function in `wiki` and `lib/*.sh`.
- Docs: `docs/cli.md` (`wiki help <cmd>`), `CHANGELOG.md` (0.7.30), `pyproject.toml`, `uv.lock`.

## What this does

```
cli_help.print_help(text): print(styled(text)) — styled only on a terminal
cli.main(["help", name, ...]):
    name in BY_NAME → alias: its target's help; else that command's help_text (or summary)
    unknown → "unknown command: <name> (try 'wiki help')", exit 1
    no name → the catalogue, as now
```
