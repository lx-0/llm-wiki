## What this does

```
main(argv):
  flags: --no-skills, --post-pull <rev>, -h/--help/help (H_UPDATE, exit 0), else
         "✗ unknown flag: <x>" exit 1
  not a checkout → "✗ Not a git checkout — <wiki> wasn't installed via install.sh. …" exit 1
  --post-pull → post_pull(...)                       (T02)
  phase 1:
    dirty (diff --quiet / diff --cached --quiet) →
      warn "Uncommitted changes in <wiki> (tracked engine files):" + `git status --short
      --untracked-files=no`
      stdin not a tty → "✗ Refusing to touch them non-interactively. …" exit 1
      confirm "Stash these changes, update, then re-apply them?" [y/N] on stdout
        no  → "✗ Update aborted — uncommitted changes left in place. …" exit 1
        yes → git stash push -m …; ok "Stashed local changes (…)" | "✗ git stash failed. …"
    before = rev-parse --short HEAD (or "unknown")
    info "Pulling latest into <wiki> …"; git pull --ff-only
      fails → stash pop quietly: warn "Restored …" | warn "Could not auto-restore …";
              "✗ git pull failed (non-fast-forward or network). …" exit 1
    stashed → the apply check: pop + ok "Re-applied …" | the two warnings | "would conflict"
    flush; execv <wiki>/wiki update --post-pull <before> [--no-skills]
```
