line wrapping to ruff's style (line length 100 from `[tool.ruff]`); it never changes
behaviour, and this task proves that rather than asserting it: the full suite (2030) and the
oracle run green on the formatted tree, `ruff format --check` reports nothing left, and `git
diff --stat` is the only review the commit needs. A second commit adds
`.git-blame-ignore-revs` naming the format commit so `git blame` (with the documented
config) attributes lines to their real authors, plus the AGENTS.md line. If the formatter
changes a file that is read as text by the engine itself (`core/config_schema.py` feeds
`docs/config.md`), the suite's parity tests are the tripwire; a real difference is a reason
to exclude that file with a comment in `pyproject.toml`, not to hand-edit it.
