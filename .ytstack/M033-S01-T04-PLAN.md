## What this does

Two passes, two commits under this task's ref. Pass A applies ruff's own fixes for the
codes whose rewrite is mechanical and behaviour-preserving (unused unpacked names →
`_name`, `subprocess.run(..., check=False)` made explicit, `try/except/pass` →
`contextlib.suppress`, nested `with` merged, `list(x)[0]` → `next(iter(x))`, list concat →
unpacking, `zip(..., strict=False)` explicit, ternaries, `yield from`, PEP 695 generics on
the 3.12 floor, …), scoped with `--select` so nothing else moves; the diff is reviewed hunk
by hunk, then `ruff format`, suite and oracle. Pass B is the hand work above, one code at
a time from `ruff check --output-format concise`, with the rule: a finding that reveals a
real defect (B015's never-asserting comparisons, B023's late-bound closures, an F841 that
dropped a result) is fixed as a defect and named in the commit message; a finding that
reveals a deliberate choice gets `# noqa` with the reason on the line; the rest is the
rename. End state: `uv run ruff check scripts hooks tests` prints `All checks passed!`.
