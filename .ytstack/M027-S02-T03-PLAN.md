## What this does

**(A) Delta-skip in `folder_index.py`:**

```
index_signature(index: FolderIndex) -> str
    # sha256 over the sorted tuple-stream (rel_path, is_dir, size, mtime)
    # of index.tree — pure mtime/size/structure diff, EXCLUDES
    # generated_at and counts (T02 carry: hash modulo frontmatter).

_load_state() -> dict / _save_state(dict)
    # STATE_DIR / "folder-index.json": {root_id: {"signature": str,
    # "last_indexed_at": iso}}; missing/corrupt file -> {} (fail-soft).

sync_root(entry, *, max_depth, recent_n, max_tree_entries,
          force: bool = False) -> SyncResult
    # walk_root -> index_signature -> compare state[root_id].signature:
    #   unchanged and not force -> SKIP: no write, no state bump,
    #     SyncResult(written=False, reason="unchanged")
    #   changed/new/force -> write_index, update state entry,
    #     SyncResult(written=True, path=...)
```

`SyncResult` = small dataclass `{written: bool, path: Path | None,
reason: str | None, signature: str}`. Note: digest file deleted by the
operator but state says unchanged → also re-write (existence check before
skip). Signature covers `recent_n`-insensitive data (full tree), so
changed walk params with identical tree still skip — acceptable until T04
makes params config-stable; `force=True` is the escape hatch.

**(B) Compile-skip wiring (config + migration, same commit):**

- `folder-index` joins `limits.compile_skip_substrate_types` default; the
  route layer (`route.py:328-335`) then Skips any `type: folder-index`
  source, and since 0.1.7 (`79a8977`) plain Skip sets `ingest_hash=True`
  — the digest is hash-recorded and never re-listed until its body
  changes (and a changed body re-evaluates correctly because the skip is
  hash-keyed). No new engine code — just the list entry.
- Migration: `migrate_list_additions` appends `"folder-index"` to
  operator vaults that already carry the key; KEY_ADDITIONS default
  updated for first-time injection.
- **Carry-constraint regression test:** an answer-shaped source under
  `raw/notes/folder/` (`type: note`, `kind: folder-deep-scan`) must NOT
  route to Skip — index = skip, answers = compile SOURCES (test via
  `decide_route` with the new default list).

Tests (~5): signature stable across walks of an unchanged tree / changes
on touch+size-change; sync_root writes on first run, skips on second
(state file asserted), re-writes on `force` and on deleted digest;
state-file corrupt → fail-soft full rebuild; decide_route Skips
`type: folder-index` but not the `raw/notes/folder/` answer shape;
migration round-trip injects `folder-index` into an existing
`["email-delta"]` list.
