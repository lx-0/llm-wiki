## What this does

Walks every `.md` file under `raw/`, `daily/`, `knowledge/`, `inbox/`, parses frontmatter, and:

1. **If `compile_role:` is present:** value must be in `VALID_ROLES` (`source-only`, `source-and-final`, `final-only`). Otherwise emit `severity=error, code=compile_role_invalid` with the bad value.
2. **If `compile_role:` is absent:** no issue (default-by-location inference handles it).

**Deferred to follow-up:** detecting cross-location-moves where the operator should re-think the inferred role. Needs git-history walk (`git log --follow --diff-filter=R`) to identify renames across top-level boundaries. Track as `.ytstack/backlog/lint-cross-location-move.md` follow-up if demand surfaces.
