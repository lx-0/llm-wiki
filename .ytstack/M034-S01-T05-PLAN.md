## What this does

- **Parity is the oracle.** These goldens must not move: `help`, `bare-no-tty`,
  `menu-help`, `menu-no-tty`, `menu-json`, `doctor-help`, `doctor-quick-json`, `version`,
  plus the three new ones.
- **One decided difference.** `menu bogus` gets the dispatcher's error style instead of the
  bash `err`. Bash printed `✗ unknown: wiki menu bogus` and the dispatcher prints
  `wiki: unknown: wiki menu bogus (try 'wiki menu help')`, the same shape as the backfill
  error. The golden changes in the port commit, and the commit says why.
- **The process count drops for the wrappers.** `wiki doctor` used to run as bash → `uv` →
  python, because bash stayed the parent without an `exec`. It now runs as dispatcher →
  doctor, the same for `menu`.
- **Left alone:** `menu.py`'s non-TTY fallback still spawns `wiki help`. The output is the
  same, and the extra hop is a follow-up for S06's surface diet, noted in the summary.
