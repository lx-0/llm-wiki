## What this does

After the final-only branch, before the substrate-type-skip:

```python
if compile_role == "source-and-final":
    from core.utils import build_index_entry, extract_wikilinks
    wikilinks = extract_wikilinks(source_content)
    log.info(
        "  source-and-final: indexing only (no distill) — %d wikilinks discovered",
        len(wikilinks),
    )
    # Build index entry: title from frontmatter or filename; sources marked
    # as "(source-and-final)" to distinguish from compiled-from entries.
    title = (_frontmatter_field(source_content, "title")
             or source.stem.replace("-", " ").replace("_", " ").title())
    today = today_iso()
    new_entry = build_index_entry(rel_path, title, "(source-and-final)", today)
    # Append if not already present (idempotent — multiple compile runs
    # don't duplicate)
    if INDEX_FILE.exists():
        existing = INDEX_FILE.read_text(encoding="utf-8")
        link_marker = f"[[{rel_path.replace('.md', '')}]]"
        if link_marker not in existing:
            with INDEX_FILE.open("a", encoding="utf-8") as f:
                f.write(f"\n{new_entry}")
            log.info("  added to knowledge/index.md")
        else:
            log.info("  already in knowledge/index.md (no-op)")
    else:
        log.warning(
            "  knowledge/index.md missing — cannot index source-and-final file",
        )
    return {"_skipped": "compile_role_source_and_final_indexed"}
```

Also add `_frontmatter_field()` helper (sibling to `_frontmatter_type` + `_frontmatter_compile_role`) for the title extraction.
