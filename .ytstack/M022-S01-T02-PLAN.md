## What this does

Neuer Flow pro File in `inbox/`:

**HTML-Branch** (`.html`/`.htm`):
1. Run `ingest-html.py --mode both` (erzeugt raw/articles/<slug>.md unverändert wie heute)
2. Bei Exit-0: `_archive_to_inbox_wiki(file_path)` (war: `file_path.unlink()`). Original-HTML lebt jetzt in `raw/inbox-wiki/`.

**Binary-Branch** (EXTENSION_MAP-hit, value == "binary"):
1. Kein LLM-classify, kein Artifact.
2. `_archive_to_inbox_wiki(file_path)`. Resultat: `raw/inbox-wiki/<orig-name>`.

**Md/Txt-Branch** (default):
1. LLM-classify → category (article/note/transcript) + suggested_name
2. `target_dir = CATEGORY_DIRS.get(category, RAW_NOTES_DIR)`; `target_path = target_dir / f"{suggested_name}.md"`; Filename-collision → suffix mit `today_iso()`
3. `shutil.copy2(file_path, target_path)` — Artifact-Kopie
4. `add_frontmatter(target_path, classification)` — Frontmatter NUR auf Artifact, nicht auf Original
5. `_archive_to_inbox_wiki(file_path)` — Original (unmodifiziert) → `raw/inbox-wiki/`

**Helper** `_archive_to_inbox_wiki(file_path) -> Path`:
```python
def _archive_to_inbox_wiki(file_path: Path) -> Path:
    RAW_INBOX_WIKI_DIR.mkdir(parents=True, exist_ok=True)
    dest = RAW_INBOX_WIKI_DIR / file_path.name
    if dest.exists():
        from datetime import datetime
        mtime = datetime.fromtimestamp(file_path.stat().st_mtime).strftime("%Y%m%dT%H%M%S")
        dest = RAW_INBOX_WIKI_DIR / f"{file_path.stem}-{mtime}{file_path.suffix}"
    shutil.move(str(file_path), str(dest))
    return dest
```

Dry-run-Pfad analog: druckt jeweils beide Ziele (`raw/<cat>/...` + `raw/inbox-wiki/...`).
