## What this does

**Backend skeleton (`backends/folder.py`)** — mirrors `backends/email.py`'s
surface (own small `RunResult` dataclass, `process_request(request_path, *,
dry_run) -> RunResult`), but the agentic read+answer lands in S04. Today:

- Reads + shape-checks the request (`root_id`, `file_path`, `topic`).
- Resolves `root_id` → `personal.watched_folders` entry → absolute
  candidate path (`expanduser(entry.path)/file_path`) and reports whether
  the file still exists (stat only — body-blind posture holds; staleness
  signal for free).
- `dry_run=True`: prints what S04 WOULD do (file, topic, informed-consent
  sentence) → success.
- `dry_run=False`: logs "folder backend lands in S04 — request left
  pending", does NOT mutate the request file (stays `pending`), returns
  `RunResult(success=False, error="folder backend not implemented (S04)")`.
  Honest non-success; no fake processed state.

**Dispatch (`cli.py`)** — `elif kind == "folder-deep-scan":
return folder_backend.process_request(...).success`; the generic
"Unsupported request type" error no longer fires for folder requests.

**Registration (`producers/folder_curiosity.py`)** —
`FolderCuriosityProducer` with `SPEC = ProducerSpec(name="folder_curiosity",
enabled_config_key="features.curiosity_loop", source_glob_config_key=None)`,
`run()` delegates to `maybe_generate_folder_requests` with the same
failure-contract-α try/except as the email wrapper. Import appended in
`producers/__init__.py` (order: suggestions → curiosity → takes →
folder_curiosity). The internal gates (watched_folders empty, no digests)
make it a cheap no-op on vaults without the feature.

Tests (~4, in the existing test file):

1. `all_producers()` contains a producer named `folder_curiosity`.
2. `_dispatch` routes a `folder-deep-scan` request to the folder backend
   (backend monkeypatched, called-with asserted); a bogus type still hits
   the unsupported error path (returns False).
3. skeleton non-dry run: returns success=False, request file still
   `status: pending` (byte-unchanged).
4. skeleton dry run: returns success=True; resolves the watched_folders
   path and reports file-exists.
