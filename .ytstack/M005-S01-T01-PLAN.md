## What this does

A new numbered instruction in the compile-time prompt tells the LLM: for `type: person|project` articles, emit a two-layer shape (compiled-truth State block above `---`, append-only Timeline below). For all other types (`concept`, `connection`, `qa`, `moc`), keep the existing atomic shape.

The State block contains:
- One-paragraph executive summary as blockquote
- `## State` -- structured fields (Role, Relationship, etc.)
- `## Action Items` -- Obsidian-Tasks-plugin syntax (`- [ ]` + optional `📅 YYYY-MM-DD`, `⏫`, `🔁`)
- `## Open Threads` -- prose bullets, waiting/blocked items
- `## What they're building` (people) / project body (projects) -- free prose with `[[wikilinks]]`
- `## See also` -- cross-links

The Timeline block (below `---`) is append-only, reverse-chronological, one entry per substrate touch:
`- **YYYY-MM-DD** | \`raw/...md\` — short note.`

Rules embedded in the prompt:
1. State block above `---` is compiled truth -- rewritten each compile pass.
2. `## Action Items` uses Obsidian-Tasks syntax exclusively (no Markdown checkboxes elsewhere with different syntax).
3. `---` separator between State and Timeline is mandatory.
4. Timeline newest-first; one entry per substrate touch.
5. Other types unchanged -- DO NOT emit the two-layer structure for `concept|connection|qa|moc`.
6. Action-Items extraction from jamie/gmeet/email substrates is S03 scope; T01 locks the schema only.
