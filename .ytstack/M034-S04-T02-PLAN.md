# M034-S04-T02 -- Task Plan

**Summary:** The seed core in Python, pure: the template walk, the two equivalences and the
overlay. Each part is held to the bash by goldens recorded from it. **Fix first:**
`--extract-custom` still dies in silence (exit 5) when a value changed type. Probed with jq
1.7.1: a scalar that became an object makes `getpath` index a string. The fix goes into the
bash and is released before the bash is recorded.

## Files

- Create: `scripts/core/jqjson.py` — JSON the way jq writes and compares it, shared by S03's
  agents and this slice:
  - `render`, moved here from `core/agents.py`, which then imports it;
  - `canonical` (what `jq -S .` gives, as a value);
  - `same` (jq's `==`: numbers by value, so `1 == 1.0`; booleans never equal to numbers);
  - `scalar_paths` (`paths(scalars)`, in document order);
  - `getpath`;
  - `setpath`, which pads arrays with nulls the way jq does.
- Create: `scripts/core/seed.py` — the pure seed core:
  - `Entry(template, dest, label, kind)` and `walk(templates_dir)`. Same order and skip rules
    as `seed_vault_templates`: only the listed templates, sorted globs, no `_dashboard-*`
    caches, a missing template skipped. The kinds are copy / overlay / list-union /
    registry / env, plus the dashboard rewrite.
  - `apply_overlay(base, overlay)`: element-wise deep merge, arrays by index, an overlay
    `null` keeps the base.
  - `compute_overlay(base, current)`: scalar leaves that differ, set into `{}`.
  - `overrides(delta)`: the count `--extract-custom` reports.
  - Copy-equivalence is bytes. The JSON branch of `_files_equivalent` is dead: it is reached
    only through the no-jq fallback, and the branch needs jq itself.
- Modify (fix first): `lib/seed.sh` `_compute_overlay`. A base path the current value cannot
  follow (a scalar that became an object) counts as changed instead of failing. Released
  with `CHANGELOG.md`, `pyproject.toml` and `uv.lock` (0.7.22), and a regression case in
  `tests/test_seed.py`.
- Create: `tests/test_seed_core.py` and `tests/golden/seed/`.
  - Per case, the bash function's output is recorded (`_apply_overlay`, `_compute_overlay`,
    `_json_canon`, run by sourcing `lib/seed.sh`; `--snapshot-update`). Python is held to
    the recording.
  - The bash-running half is deleted with the bash in T05; the goldens stay.
  - `walk` is held to the labels of `tests/golden/bash/seed-check-unseeded.txt`, in order.
    That golden lists every seedable file the way the bash walks them.

## Cases

- **Overlay apply:**
  - the fixture's `graph.json` with `{"scale": 1.5}`;
  - a nested override and a new key;
  - a sparse overlay array (nulls keep the base elements);
  - an overlay array longer than the base;
  - an overlay `null`;
  - a scalar replaced by an object;
  - no overlay (the bash then `cat`s the template).
- **Overlay compute:**
  - a changed scalar, an added key, a nested change;
  - an array element (gives nulls before it);
  - a removed key or an emptied container (not expressed);
  - `true` vs `1`, and `1` vs `1.0`;
  - the type change (the fix);
  - nothing changed (`{}`).
- **Canonical:** reordered keys, non-ASCII, nested arrays.
