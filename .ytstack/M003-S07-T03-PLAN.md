## What this does

Today: silent failure. If `dashboard_stats.py` or `dashboard_lint.py` crash when invoked from `wiki lint` / `wiki seed` / etc, the user sees a clean banner and nothing else. Stale cache, no signal.

After: stderr is captured to `mktemp`. On non-zero exit, the existing `warn` helper (yellow ✗) prints the script's stderr message to the operator. The wrapper still returns 0 (best-effort) so the parent `cmd_*` doesn't abort.

Pseudocode:
```bash
_refresh_dashboard_stats() {
  local tmp; tmp=$(mktemp)
  if ! uv run --quiet --project "$WIKI_DIR" python "$WIKI_DIR/scripts/dashboard_stats.py" 2>"$tmp"; then
    warn "dashboard stats refresh failed: $(<"$tmp")"
  fi
  rm -f "$tmp"
}
```

Same shape for `_refresh_dashboard_lint`.
