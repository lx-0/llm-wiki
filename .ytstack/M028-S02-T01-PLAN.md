## What this does

`_execute_deletes(actions, vault, *, allowed)`:
- If `not allowed`: log that N nominated files were NOT deleted (superseded
  instead), return `[]`. (S01 behaviour preserved end to end.)
- Else, `trash_root = vault/".trash"/<ts>`; for each `deleted` rel-path: resolve;
  skip if missing or not under `KNOWLEDGE_DIR` (safety); `path.rename(trash_root/
  rel)` (mkdir parents) — the move IS the backup. Returns the executed rel-paths.
- Before moving, `_clear_index_rows(INDEX_FILE, {resolved deleted}, vault)` drops
  index lines whose wikilink resolves to a doomed file (resolution needs the file
  present, so this runs first).

`apply()`: after `_execute_renames`, `executed_deletes = _execute_deletes(actions,
ROOT_DIR, allowed=False)`; extend the divergence call's accounting so a declared+
executed deletion is not flagged (pass executed deletes into `_divergence` or fold
into actions — keep `_divergence` signature stable by treating executed deletes as
"declared"). For T01 `allowed=False` so `executed_deletes` is always `[]`.
