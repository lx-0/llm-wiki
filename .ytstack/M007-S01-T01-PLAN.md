## What this does

`scripts/core/compile_role.py` exports the type, the valid-values frozenset, and a pure inference function with the following semantics:

```python
from typing import Literal
from pathlib import Path

CompileRole = Literal["source-only", "source-and-final", "final-only"]
VALID_ROLES: frozenset[str] = frozenset({"source-only", "source-and-final", "final-only"})

# Location-class → inferred role when frontmatter omits compile_role
LOCATION_DEFAULTS: dict[str, CompileRole] = {
    "raw": "source-only",
    "daily": "source-only",
    "inbox": "source-only",
    "knowledge": "source-only",  # knowledge/ pages are compile OUTPUT;
                                  # if compile re-runs them they distill (no-op when up-to-date)
}

def infer_compile_role(
    path: Path,
    frontmatter: dict,
    *,
    default_by_location: bool = True,
    vault_root: Path | None = None,
) -> CompileRole:
    # 1. Explicit override always wins
    explicit = frontmatter.get("compile_role")
    if explicit is not None:
        if explicit not in VALID_ROLES:
            raise ValueError(f"invalid compile_role: {explicit!r}")
        return explicit  # type: ignore[return-value]
    # 2. Default-by-location if enabled
    if not default_by_location:
        return "source-only"
    location_class = _location_class(path, vault_root)
    return LOCATION_DEFAULTS.get(location_class, "source-only")

def _location_class(path: Path, vault_root: Path | None) -> str:
    """Return first known top-level segment (raw/daily/knowledge/inbox) or '' if none."""
    # Strategy: walk path parts; first segment matching LOCATION_DEFAULTS wins.
    # If vault_root provided, make path relative first; otherwise scan parts as-is.
    parts = path.relative_to(vault_root).parts if vault_root else path.parts
    for part in parts:
        if part in LOCATION_DEFAULTS:
            return part
    return ""
```

**Failure modes:**
- Invalid enum value in frontmatter → raises `ValueError` (loud, T03 lint check surfaces gracefully)
- Path outside known top-levels → falls back to `"source-only"` (safe default; consumer can decide policy)
- `vault_root=None` → uses path parts directly (heuristic; works for both absolute and relative paths as long as a known segment appears anywhere)

**Config dependency: NONE in T01.** The `default_by_location` parameter is plumbed in by T02 callers from `CONFIG.compile_role_default_by_location`. Pure function = testable + composable + decoupled from global config.

**T02/T03/T04 consume this module:**
- T02: config knob `compile_role_default_by_location: bool = true` + migration entry; callers pass `CONFIG.compile_role_default_by_location` into the function.
- T03: lint imports `VALID_ROLES` to validate enum values in `compile_role:` frontmatter; uses `infer_compile_role` + git-history to detect cross-location moves without explicit override.
- T04: pytest formalization with full coverage (schema, default-inference, lint warnings, config-knob toggle, vault_root handling).
