# M028-S01-T05 -- Task Plan

**Summary:** Replace the unverified `print(result_text)` with ground-truth
filesystem-delta reporting: compute what actually changed (git porcelain when
present, else a pre/post mtime snapshot), print it, and WARN when the real
deletion count exceeds what the agent declared in its proposal block — the exact
issue-#5 failure (claimed 6, deleted 17).

## Files

- Modify: `scripts/facts/correct_apply.py` — add pure helpers `_parse_porcelain`,
  `_snapshot`, `_delta_from_snapshot`, `_divergence`, plus `_git_delta` (subprocess)
  and `_report_filesystem_delta`; wire a before-snapshot + after-report into `apply()`.
- Modify: `tests/test_correct_apply.py` — unit-test the pure helpers.

## What this does

- `_parse_porcelain(out)` → `{created, modified, deleted, renamed}` from
  `git status --porcelain -z`/`--porcelain` text (codes: `D`→deleted, `R`→renamed,
  `??`/`A`→created, `M`→modified). Pure, testable without git.
- `_git_delta(vault)` → run `git status --porcelain` via `subprocess.run` (list
  args, no shell — `execFileSync` discipline); `None` if not a git repo / git absent.
- `_snapshot(knowledge_dir)` → `{path: (mtime_ns, size)}`; `_delta_from_snapshot(
  before, after)` → created/modified/deleted (non-git fallback, exit-criterion #2).
- `_divergence(actions, delta)` → list of warning strings. Load-bearing check:
  `len(delta["deleted"]) > len(actions["deleted"])` → "engine deleted N files but
  the agent declared M" (issue #5). Also flags rename count drift.
- `_report_filesystem_delta(delta, divergences)` → print structured
  created/modified/deleted/renamed counts+paths; `log.warning` each divergence.

In `apply()`: capture `before = _snapshot(...)` early **only if not a git repo**;
after `_execute_renames`, compute `delta = _git_delta(ROOT_DIR) or
_delta_from_snapshot(before, _snapshot(...))`, then `_report_filesystem_delta(
delta, _divergence(actions, delta))`. The filesystem is the record, never the
agent narrative.
