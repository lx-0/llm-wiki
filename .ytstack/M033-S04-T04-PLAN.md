## What this does

`run_sdk_query` reads as its mechanics list: sanitize env → options → stream → one of
three endings (timeout, failed stream, clean end), each building the `SdkRunResult` from
the same accumulated state and recording the same cache-inclusive totals. Nothing a
caller, a test or the operator's logs can observe changes: the same `ClaudeAgentOptions`
kwargs, the same per-message timeout, the same log lines, the same result fields on every
path.
