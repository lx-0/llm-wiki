## What this does

Two additions on top of T01's `FolderIndex`:

```
INDEX_DIR = RAW_DIR / "index"            # local convention, like email.py's DEEP_SCAN_DIR

render_index(index: FolderIndex, *, max_tree_entries: int) -> str
write_index(index: FolderIndex, *, max_tree_entries: int) -> Path
```

`render_index` — pure function `FolderIndex -> markdown str`:

- Frontmatter (email-deep-scan style, `_render` in
  `curiosity/backends/email.py` is the sibling): `type: folder-index`,
  `root_id`, `root_path` (JSON-quoted, unmasked), `generated_at` (ISO),
  `counts` flattened (`files`/`dirs`/`skipped_excluded`/`skipped_depth`/
  `errors`), `truncated: true|false`.
- Body, two sections for the S03 producer (single consumer):
  - `## Recent changes` — `index.recent` as list lines
    `` - `rel/path` — <ISO date> · <human size> `` (already top-N capped by
    `recent_n` at walk time).
  - `## Tree` — `index.tree` as an indented listing (indent = rel_path
    depth, dirs get a trailing `/`, files get `· <human size>`). Capped at
    `max_tree_entries` lines; when capped, append marker
    `_… <N> more entries omitted (size cap)_` and set `truncated: true`
    in frontmatter.
- Deterministic: pure function of the dataclass — same `FolderIndex` in,
  byte-same markdown out (T03 delta-skip will compare content; note that
  `generated_at` varies per walk — T03 must hash modulo frontmatter or
  reuse walk-level signals, ITS problem, noted here so it isn't forgotten).
- Names land verbatim (umlauts/spaces, no masking, no escaping beyond
  what backtick-wrapping needs).

`write_index` — renders, `INDEX_DIR.mkdir(parents=True, exist_ok=True)`,
writes `INDEX_DIR / f"{index.root_id}.md"` (root_id is operator-chosen
config `id`, used as-is), returns the path. Plain `write_text` (same
posture as email backend).

**Out of scope here, explicitly:** marking `folder-index` compile-skip via
`CONFIG.limits.compile_skip_substrate_types` is a config-default change
(+ migration, same-commit hard rule) → that lands in **T03** together with
the skip-record discipline. The `type: folder-index` frontmatter written
here is the hook it will key on. Carry-constraint reminder for T03:
index = compile-skip, but `raw/notes/folder/` answers = compile SOURCES.

Tests (extend existing file, ~5):

1. render: frontmatter has `type: folder-index` + root_id + counts;
   body has both sections; recent line carries date + size.
2. render is deterministic: same FolderIndex → byte-identical string.
3. size cap: tree with more entries than `max_tree_entries` → truncated
   listing + omitted-count marker + `truncated: true`; recent section
   unaffected.
4. unmasked: umlaut/space filename appears verbatim in the rendered body.
5. write_index: monkeypatch `folder_index.INDEX_DIR` to tmp_path → file
   lands at `<tmp>/<root-id>.md`, content == render_index output,
   re-write overwrites (one digest per root).
