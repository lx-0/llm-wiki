# M003-S07-T01 — Task Plan

**Summary:** Remove `_dashboard-stats.md` from `lib/seed.sh:seed_vault_templates`. Cache files are producer-only outputs; `wiki seed --force` clobbering them with the placeholder template was causing the Engine-status block on the Dashboard to silently regress to all-zeros.

**Hot-patch context:** This task is being applied out of S07's normal sequence because the bug recurred mid-conversation while we were planning S02. User ran `wiki seed --force` (or `wiki update`), it clobbered the live cache, Dashboard went back to zeros. Fixing `seed.sh` immediately stops the bleed; S07's other tasks (T02 flush.py stderr, T03 wiki shell stderr, T04 pytest fixture) follow in their planned order.

## Files

- **Modify**: `lib/seed.sh:189-194` — delete the `_seed_file` call for `_dashboard-stats.md`, replace with a comment block explaining why cache files aren't seeded.
- **Modify**: `wiki:460` — update the `wiki seed --help` "WHAT IT DOES" list: drop `_dashboard-stats.md`, add a note that cache files (`_dashboard-*.md`) are not seeded.

## What this does

`_seed_file` (`lib/seed.sh:13-32`) treats `_dashboard-stats.md` as a regular template: copies template→target if target missing, OR overwrites target with template if `--force=1`. The template at `templates/_dashboard-stats.md` contains all-zero counts + a "Placeholder — refreshes after first wiki flush" line. Bytegenau identisch mit dem clobbered state we observed.

Removing the call means: target is never created or overwritten by seed. Cache lifecycle becomes producer-only:
- First boot: target file doesn't exist. Dashboard's `![[_dashboard-stats]]` embed shows empty (acceptable — operator runs `wiki flush` once).
- Steady state: every `wiki flush` / `wiki compile` / `wiki lint` / `wiki correct` writes the cache fresh via `dashboard_stats.py` (already wired at `wiki:248-250`).
- `wiki seed --force` no longer touches the cache. AGENTS.md + dashboard.md still get force-overwritten as before (those ARE templates).

The help-text change keeps user expectations aligned — "WHAT IT DOES" was advertising cache-file seeding which is now (correctly) gone.
