# M034-S03-T01 -- Task Plan

**Summary:** The agent registry in Python, `scripts/core/agents.py` (ty-gated). It is the pure
layer under the S03-T02 commands; nothing calls it yet.
- **The agents:** `claude` / `codex` / `gemini` / `cursor`, each with its detection dir and
  config file.
- **Scopes:** `user` is `$HOME`, `project` is the vault root. Presence and config paths
  follow from them.
- **One hook-command grammar.** `HOOK_CMD_RE` serves the installed probe, the merge and the
  uninstall. There are three drifted copies in the bash today; the uninstall's matches
  nothing current (S03-T02).
- **`hook_cmd(script)`:** `cd '<.wiki>' && [UV_PROJECT_ENVIRONMENT='<venv>' ]uv run python
  hooks/<x>.py`. It is byte-identical to the bash, and the hook commands stay as they are
  (locked decision). The prefix comes from `UV_PROJECT_ENVIRONMENT`, which the bootstrap
  exports by lib/common.sh's one rule.
- **`payload(agent)`:** the four per-agent hook blocks (Gemini's timeouts in ms, Cursor's
  `version: 1` and bare entries). `render()` writes them as jq does: 2-space indent, UTF-8
  as-is, a trailing newline.

## Files

- Create: `scripts/core/agents.py`.
- Create: `tests/test_agents_registry.py`. The parity tests run the bash
  (`source lib/common.sh lib/agents.sh; agent_payload X`) and compare text, byte for byte,
  with and without a cloud-vault env prefix and with a vault path that contains spaces.
  The grammar's cases cover the current format, the older
  `uv run --project .wiki python .wiki/hooks/…` format, `_transcript`, and foreign commands
  that must not match.
