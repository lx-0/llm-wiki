## What this does

Adds a new top-level Markdown section `## 🛡 Lint triage` to `templates/dashboard.md`. Body uses Dataview JS to read `_dashboard-lint.md` frontmatter (`orphans_count`, `stale_count`, `missing_backlinks_count`, `failed_flushes_count`) and emit four callouts.

For each queue:
- Count > 0: render as `> [!warning]- {Title} ({N})` (collapsed-by-default callout) with body `![[_dashboard-lint#{Section}]]`.
- Count == 0: render as `> [!success] {Title} (0)` with no body — auto-collapses, signals "queue empty" green.

Pseudocode (DataviewJS):
```js
const lint = dv.page("_dashboard-lint");
const queues = [
  { key: "orphans_count", title: "Orphans", section: "Orphans" },
  { key: "stale_count", title: "Stale", section: "Stale" },
  { key: "missing_backlinks_count", title: "Missing backlinks", section: "Missing backlinks" },
  { key: "failed_flushes_count", title: "Failed flushes", section: "Failed flushes" },
];
for (const q of queues) {
  const n = lint?.[q.key] ?? 0;
  if (n === 0) {
    dv.paragraph(`> [!success] ${q.title} (0)`);
  } else {
    dv.paragraph(`> [!warning]- ${q.title} (${n})\n> ![[_dashboard-lint#${q.section}]]`);
  }
}
```

Insertion point: after the Engine-status callout block (which currently embeds `![[_dashboard-stats]]`), before the Run section. Verify by reading templates/dashboard.md head-to-tail.
