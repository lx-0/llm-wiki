1. **Shard** the 85 items across 8 read-only agents (~11 each). Each one reads its items, then
   re-derives status from the CODE and history — never from what the item says about itself —
   and returns per item: verdict (open / partial / shipped / superseded / stale premise),
   what is left in one sentence, effort S/M/L, a tier proposal, evidence (file:line, commit,
   test). No agent writes anything; the live vault is read-only.
2. **Refute** every shipped / superseded / stale-premise verdict with a separate agent that
   tries to prove it wrong (a wrong "done" deletes real work from the radar; an over-cautious
   open costs nothing). Only verdicts that survive move.
3. **Apply** the moves and rewrite PRIORITY.md; check its claims against the agents'
