## What this does

Deeper sibling to `check_two_layer_pages`. T01 confirms each Action Items line starts with `- [ ]` / `- [x]` (prefix sanity). T02 validates the Obsidian-Tasks-plugin metadata that follows on each line. Rules:

- **📅 due date.** If `📅 ` (date emoji + space) appears on an Action Items line, the next 10 chars MUST be a valid `YYYY-MM-DD`. Else: `warning: action_item_invalid_due_date`.
- **⏫ priority.** If `⏫` appears, must be preceded by whitespace and followed by whitespace or end-of-line — no concatenated glyphs. Else: `warning: action_item_malformed_priority`.
- **🔁 recurrence.** If `🔁 ` appears, must be followed by non-empty content on the same line (e.g. `every week`). Bare `🔁` at end of line → `warning: action_item_empty_recurrence`.

Scope: same as `check_two_layer_pages` — only `knowledge/people/*.md` + `knowledge/projects/*.md` with matching `type:`. Skip files that don't have a `## Action Items` section. One warning per file per rule (so a file with three malformed due dates gets one warning, not three) — keeps the report scannable; operator can grep for full detail.

Severity: all `warning` (these are quality nudges, not structural breaks). The two-layer-structure errors stay in T01's domain.
