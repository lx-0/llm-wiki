## What this does

Adds the dual to T01's carry-forward: when substrate contains a resolution signal, demote the matching State item to Timeline.

Rules:

1. **Resolution signals.** Phrases that indicate a previously-open commitment is now done:
   - "Sent the deck", "delivered X", "shared the doc", "shipped Y" → resolves "I'll send X" / "I'll deliver Y"
   - "Met with Bob yesterday" / "Bob and I synced" → resolves "follow up on Bob intro"
   - "Decision made: we'll do X" → resolves "deciding on X"
   - Past-tense first-person announcements of a previously-committed action
2. **Matching.** Use task-phrase similarity (verb + object). The resolution doesn't have to be word-for-word; "send the deck" matches "share the slides for Q3" if the substrate makes the connection clear.
3. **Demotion mechanic.** When a match is detected:
   - REMOVE the `- [ ]` line from State `## Action Items`
   - APPEND a new Timeline entry of the form `- **${today}** | \`${source_path}\` — [resolved] <original task summary>.`
   - Do NOT also keep the State line. One item, one place.
4. **Open Threads resolve too.** "Hetzner came back with capacity" resolves "Waiting on Hetzner infra-capacity decision" → same demotion path.
5. **Conservative.** If the resolution signal is ambiguous, do NOT demote. Leave the item in State; add a Timeline entry citing the partial-resolution mention. Operator can manually move to Timeline.
6. **Don't double-demote.** If a State item is `- [x]` (operator-checked, T01 preserved), and substrate provides resolution evidence on the same item, that's a confirmed-resolved → demote with `[resolved-manual+substrate]` marker.
