## What this does

Biome 2.5 is the stack default (replaces ESLint + Prettier in one binary). The config mirrors the
code's existing conventions (2-space indent, single quotes, semicolons) so the mechanical diff stays
a whitespace/wrapping diff. Lint runs the `recommended` preset; findings in files that S04/S05
delete anyway (`renderer.ts`, `cockpit.ts`, `atlas.ts`, `triage.ts`, `browse.ts`, `settings.ts`,
`onboarding.ts`) are fixed only when the fix is a one-liner — anything deeper is listed in the
summary and dies with the file. No rule is disabled project-wide to make the old renderer pass.
`.svelte` support is partial in Biome; `svelte-check` (T05) covers component typing.
