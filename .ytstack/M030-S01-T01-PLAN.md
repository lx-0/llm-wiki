# M030-S01-T01 -- Task Plan

**Summary:** Corpus walker + slug mapper: enumerate `knowledge/**/*.md` (excluding `knowledge/index.md`), derive flat global kebab-case slugs that are FIXPOINTS of the server-side slugification, detect collisions deterministically, persist the slug↔path manifest via `core.state_store`.

## What this does

`scripts/publish/corpus.py`, pure functions, no network:

- `server_slug(name: str) -> str` — Python port of context-mcp's `slugifySkillName` (skill-validation.ts:151-158): NFKD-normalize + strip combining marks (unicode fold to ASCII), lowercase, replace every `[^a-z0-9]+` run with `-`, trim leading/trailing `-`, cap at 120 chars (re-trim after cap). Must be a fixpoint: `server_slug(server_slug(x)) == server_slug(x)` for all x.
- `map_slugs(knowledge_dir: Path) -> dict[str, Path]` — walk via `core.links.iter_articles`, skip `knowledge/index.md`; base slug = `server_slug(path.stem)`; on collision between two different paths, BOTH get the disambiguated form `server_slug(f"{parent.name}-{stem}")` deterministically (order-independent); a collision surviving disambiguation raises `PublishCollisionError` listing all colliding paths (deterministic failure, no silent pick).
- `load_manifest() / save_manifest(mapping)` — persisted at `STATE_DIR / "publish.json"` via `core.state_store.store_for` (locked/atomic), schema `{"articles": {slug: {"path": "<knowledge-relative posix path>"}}}`; hash + delta fields come in T04, wiki metadata in S02 — schema is additive.
- Slug stability rule: an article already in the manifest keeps its slug as long as its path is unchanged, even if a later collision would newly disambiguate it (renames upstream are retractions + re-adds; stability protects retraction ids).

`tests/test_publish_corpus.py` (fixture vault in tmp_path, no real vault access — conftest write-guard applies):

- fixpoint property on adversarial names: umlauts/NFKD (`Über-Städte`), emoji, leading/trailing hyphens+digits, >120-char names, all-symbols name (→ empty slug must raise, not pass through)
- collision: `concepts/alex.md` + `people/alex.md` → `concepts-alex` / `people-alex`, deterministic in both walk orders
- `knowledge/index.md` excluded; nested subdirs (MOCs/) included via iter_articles
- manifest round-trip through StateStore; slug stability across a re-map with an added colliding file

## Deviations decided during TDD

- `map_slugs` returns `{slug: knowledge-relative posix str}` (not `Path`) — matches the manifest schema directly, avoids a lossy round-trip.
- `manifest_store` constructs `StateStore` directly instead of `store_for` — a fresh instance per call observes disk truth (the singleton cache would mask persistence in tests); publish has a single consumer, so the sharing singleton buys nothing.
- Verified against the real TS source: `slugifySkillName` does NOT truncate to 120 — `MAX_NAME_LENGTH` is a separate `name`-argument validation, so the mapper rejects overlong stems instead of capping slugs. The diacritics strip is exactly the U+0300–U+036F block (not all combining marks).
