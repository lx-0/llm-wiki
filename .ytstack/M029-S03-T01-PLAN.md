# M029-S03-T01 -- Task Plan

**Summary:** Turn the minimal status list into a real, glanceable, **live-polling**
health window — running state (color), per-channel freshness, last-capture time.
All in `desktop/`; reuses the verified status/control IPC.

## Files

- Modify: `desktop/src/renderer.ts` — poll `window.listeners.status()` every 3 s
  (clear interval on unload); render a card per listener: colored state
  (running=green / stopped=grey / zombie=amber), mic+sys freshness ("Xs ago" +
  ✓), last-capture wall-clock time. Keep the Start/Stop button (S02), still
  disabled while busy.
- Modify: `desktop/src/index.css` — minimal styling: state dot colors, card
  layout, monospace timestamps.
- Modify: `desktop/index.html` — heading/structure only if needed.

## What this does

Pure presentation over the already-verified `getListenerStatus` IPC. Live poll
makes it a glanceable health surface (the "is it running before my meeting" use
case). No new backend, no engine call. Format `lastCaptureAtMs` → local time
(`toLocaleTimeString`).
