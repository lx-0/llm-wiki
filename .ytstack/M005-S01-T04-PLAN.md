# M005-S01-T04 -- Task Plan

**Summary:** Pytest-level smoke test that the new Instruction 3 (two-layer schema) reaches the rendered compile prompt unchanged. Fast, deterministic, no LLM call. Validates the plumbing; LLM-emission quality is S03 territory.

## What this does

The T04 smoke test uses `core.prompts.render` to render the compile prompt with dummy values for every `${var}` placeholder and asserts the rendered output contains the schema markers introduced in T01. Why this is the right T04 scope:

- **Catches regression at the prompt-pipeline level**: if a future edit accidentally breaks the placeholders, removes the section, or renames a header, the test fails fast.
- **Doesn't require LLM**: no API key, no network, runs in CI in milliseconds.
- **Doesn't pretend to validate LLM emission**: that's a S03 deliverable (T05 there = real-substrate canary). T04 is a plumbing test — schema rules reach the prompt the LLM sees.

Why not run actual `compile.py --dry-run`: dry-run skips the LLM call but doesn't print the rendered prompt; the prompt is only assembled inside `compile_file()`. To smoke-test the prompt directly, calling `render()` is the most surgical path.
