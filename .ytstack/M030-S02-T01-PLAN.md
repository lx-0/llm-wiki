## What this does

- `ContextMcpClient(endpoint, token, timeout=None, transport=None)`: httpx.Client with explicit `httpx.Timeout` (connect/read/write/pool) and injectable transport (tests use `httpx.MockTransport`). JSON-RPC over `POST <endpoint>`: lazy `initialize` handshake once per instance (protocolVersion 2025-06-18, clientInfo llm-wiki/publish), then `notifications/initialized`; subsequent calls carry `MCP-Protocol-Version` + `Authorization: Bearer <token>` + `Accept: application/json, text/event-stream` (server answers plain JSON — verified live: 401 unauthenticated returns a JSON-RPC error body with `www-authenticate` resource metadata).
- `call_tool(name, arguments) -> dict` (the MCP result object); `tool_text(result)` helper extracts the first text content block. Error ladder: HTTP≠200 or JSON-RPC `error` → `PublishClientError` (message includes code/status + body excerpt); tool result `isError: true` → `ToolCallError` carrying the tool's text (the S03 executor classifies secret-gate rejects from this).
- `resolve_token() -> str`: `MEINKONTEXT_TOKEN` from the environment (dotenv from `<vault>/.claude/.env` is already bootstrapped by core.config); missing → actionable error pointing at context-mcp's live-import runbook.
- Config: new `Publish` dataclass — `enabled: bool = False`, `endpoint: str = ""`, `wiki_slug: str = "llm-wiki"`, `wiki_name: str = "LLM Wiki"`; wired into `WikiConfig`, `config.example.yaml`, and the migration policy tables (token stays .env-only, no schema key).
