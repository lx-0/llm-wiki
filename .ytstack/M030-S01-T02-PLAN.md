# M030-S01-T02 -- Task Plan

**Summary:** Wikilink normalization for served articles: every link that resolves to a published knowledge article becomes `[[target-slug]]` (heading/alias/embed-bang/table-escape preserved); unresolvable targets and targets outside the publish set degrade to plain text.

## Files

- Create: `scripts/publish/render.py`
- Create: `tests/test_publish_render.py`

## What this does

`normalize_links(text, source, vault, slug_by_relpath, knowledge_dir) -> (new_text, changed)`:

- walks lines outside frontmatter + code fences, matching `WIKILINK_RE` — reuses `core.links` primitives (`resolve_link`, `strip_table_escape`, `_strip_frontmatter_and_fences`; private-import documented as in-repo single-source reuse, same policy as retarget_links' consumers)
- resolvable link whose knowledge-relative path is in `slug_by_relpath` (the inverted T01 mapping) → target replaced by the slug; `!`, `#heading`, `|alias`, table-escape `\\|` all preserved
- everything else (unresolvable, outside knowledge/, `knowledge/index.md`, media embeds) → whole link degrades to plain text: alias text if present, else the clean target (heading dropped, bang dropped)
- returns the rewritten text + change count; text without links round-trips byte-identical
