# M034-S02-T03 -- Task Plan

**Summary:** The setup wizard in Python. `wiki setup` is the wizard and then the hooks step;
`wiki config wizard` is the wizard alone. The bash pieces go with it:
- `cmd_setup`, `help_setup`, `config_cmd_setup_wizard`, its validators and `_probe_ollama`;
- `config_path`;
- `lib/ui.sh`'s `ask`;
- the transitional `config)` line.

Planning found a defect, fixed first in its own commit: `features.procmail_execution` has never
had a reader.

## Three commits, in this order

1. **Bash record (committed before any port code — the S02-T02 lesson).** The wizard paths not
   yet in the oracle:
   - `config-wizard-validates`: `wiki config wizard`. A non-http URL is refused, then the
     current one taken; haiku; an out-of-range hour, then 7; procmail y; local-LLM y;
     global skill y.
   - `setup-with-hooks`: `wiki setup`, every wizard answer Enter, then `y` to the hooks step
     and the hooks installer's own answers (`1`, `1`, `y`) on the same stdin. In bash one
     process reads them all; after the port a child reads the rest. That is the case T01's
     byte-wise reads exist for.
2. **Fix: the procmail switch switches.** `adapters/mailbox/allinkl.py:apply` refuses a real
   (non-dry-run) write when `CONFIG.features.procmail_execution` is false.
   - The default stays `True`, so nothing changes for a vault that left it unset or set it
     true (lxw sets it true explicitly).
   - `H_CONFIG`'s "off by default" becomes the truth: on by default, the All-Inkl filter
     honours it.
   - A test is watched failing first. DECISIONS and a CHANGELOG `Fixed` entry go in the same
     commit.
3. **The port:**
   - `scripts/setup_wizard.py`: the six questions with the bash's texts, defaults,
     validators (`http(s)://`; hour 0–23), the Ollama probe (shared with `config_cli`) and
     the writes through `core.config`'s `set`.
   - `wiki setup`: a catalogue `py` command (handler `setup_wizard.py`). Its banner is the
     command's own (`wiki setup` + subtitle). After the wizard, "Now install hooks into agent
     configs?"; yes runs `<.wiki>/wiki hooks install` as a child that inherits stdin.
   - `wiki config wizard`: `config_cli` routes it to the same wizard.
   - Deleted: the bash pieces listed above. `select_one` / `confirm` stay for
     `lib/hooks.sh` and `cmd_update`.
   - `H_SETUP` comes from `help_setup`. Corrected with the move: it lists the 6 questions
     (the bash text said 5 and left out the global skill).
   - Decided differences, each taken into its golden:
     - the wizard's `confirm` prompts on stderr (T01);
     - the procmail info line drops "Default OFF." (the default has been on since the first
       release).
