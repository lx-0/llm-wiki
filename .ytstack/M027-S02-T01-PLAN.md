## What this does

Pure walk logic over one `personal.watched_folders` entry (`kind=local`),
consuming the S01 config shape `{id, kind, path, include?, exclude?}`:

```
walk_root(entry: dict, *, max_depth: int, recent_n: int) -> FolderIndex

FolderIndex (dataclass):
  root_id: str                      # entry["id"]
  root_path: str
  tree: list[IndexEntry]            # depth-capped, sorted, dirs-first
  recent: list[IndexEntry]          # top-N files by mtime desc
  counts: {files, dirs, skipped_excluded, skipped_depth, errors}
  generated_at: datetime

IndexEntry (dataclass):
  rel_path: str                     # relative to root, as-is (NO sanitization)
  is_dir: bool
  size: int | None                  # files only
  mtime: float
  ext: str                          # lowercased suffix, "" for dirs
```

Behaviour, pinned:

- **Body-blind invariant:** the walker NEVER opens a file. `os.scandir` +
  `entry.stat(follow_symlinks=False)` only. No `open()`, no hashing, no
  content sniffing anywhere in the module.
- **Depth cap:** directories below `max_depth` are not descended into;
  count them in `skipped_depth`. Cap value is a function parameter here —
  lifting it to a config knob happens in T04 (CLI wiring) together with the
  migration entry, per the config-migration hard rule.
- **include/exclude:** `fnmatch`-globs from the config entry, matched against
  `rel_path`. `exclude` wins over `include`; empty/missing include = include
  all. Excluded dirs are not descended into (`skipped_excluded`).
- **Symlinks:** never followed (no cycle risk, no escape from the root).
  Recorded as plain entries with `is_dir=False`.
- **Errors fail soft:** `PermissionError` / `OSError` on a dir or stat →
  skip that entry, increment `counts.errors`, keep walking. A nonexistent
  root raises `ValueError` (caller's config problem, loud).
- **Determinism:** tree sorted dirs-first then name; `recent` ties broken by
  rel_path — same fixture in, byte-same model out (T02/T03 depend on this
  for delta hashing).
- **No sanitization** of any path/name (DECISIONS 2026-06-07).

Tests (tmp_path fixture tree with nested dirs, dotfiles, an excluded subtree,
a too-deep subtree, files with distinct mtimes):

1. body-blind: monkeypatched `builtins.open` raising → walk still succeeds
2. depth cap honored + counted
3. include/exclude globs honored, exclude wins, excluded dir not descended
4. recent list = top-N by mtime desc, deterministic tie-break
5. permission-denied dir → errors counted, walk completes
6. filenames land as-is in the model (umlauts/spaces, no masking)
7. nonexistent root → ValueError
