## What this does

The Overview is the window the panel's first nav item opens — the place for the numbers and the charts the 360 px popover has no room for. This task makes it exist and ship: opened from the nav, themed, sized, captured by the harness; with the hero figure (the one number a dashboard leads with), the four stat tiles (label + value, the figure contract — not a one-bar chart each), and the first real chart. "Notes updated per day" is a single-series column chart — magnitude over time, so one hue (the accent: validated as slot 1 against both surfaces, all checks pass), bars thin with a surface gap, labels selective (today), a tooltip per bar, text in text tokens. The derivations behind it already exist in the panel's status module and move to `lib/` so both windows count the same way; the label changes to "updated" because mtimes say touched, not created. T03 fills the remaining grid cells (type bars, capture heat strip, health, next up) and adds the table view.

Shape at 900 × 700: header 44 · hero + tiles row 96 · chart grid (2 columns, the first chart in the top-left cell, the other cells rendered as empty placeholders only until T03 — not in the shipped T02 build; the grid starts with one card and grows). Window content scrolls when the operator shrinks it; nothing clips.
