# M034-S01-T07 -- Task Plan

**Summary:** Smoke every consumer of `<vault>/.wiki/wiki` against the scratch vault at S01's
head, the way each one invokes it:
- the desktop app's six argv lists;
- the eight Obsidian shell-command buttons;
- a `~/.local/bin/wiki`-style symlink, run from outside the vault;
- the use-llm-wiki skill's commands.

The skill pass found a defect, fixed here. The skill tells agents to run the vault dashboard
as `uv run --project .wiki python .wiki/scripts/health.py --vault .`. On a cloud-synced vault,
that bare `uv run --project .wiki` ignores the venv-location rule and recreates `.wiki/.venv`
inside iCloud. That is the eviction / SIGKILL class from 2026-09-17, and engine-layout's hard
rule says "never". No `wiki` command reached `health.py`.

## The matrix

The calls that cost LLM tokens are not run verbatim: compile, query, and the agents' SDK
spawns. They are reduced to the same dispatch with a no-cost flag (`--help` / `--dry-run`),
and the summary says which.

| Consumer | Spawn shape | Calls |
| --- | --- | --- |
| Desktop app | no shell, `cwd` = vault, stdin `/dev/null`, PATH = the app's `augmentedPath()` | `doctor --json`, `menu --json`, `collect --list --json` (JSON parsed); `compile --progress-json` → `compile --help`; `query … --brief --json` → `query --help`; `triage <action> <stem>` → `triage --help` |
| Obsidian buttons | `/bin/zsh -c "<line>"`, `cwd` = vault (the plugin's default shell, no PATH augmentation in template or live vault) | `lint --structural-only`, `refresh-dashboards` verbatim; `compile`, `compile --all` → `--help`; the four `agent` lines with `--dry-run` (the date variable filled in) |

| use-llm-wiki skill | `cwd` = vault | `status`, `doctor`, `doctor --json`, `doctor --quick --json`, `menu --json`, `stats` (after the fix), `dedup --suggest-only` |
