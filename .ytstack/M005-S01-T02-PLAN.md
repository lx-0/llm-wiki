# M005-S01-T02 -- Task Plan

**Summary:** Update `templates/AGENTS.example.md` schema doc so the **People Articles** and **Project Articles** sections describe the two-layer State + Timeline shape (matching the new Instruction 3 in `prompts/compile_main.md`).

## What this does

`templates/AGENTS.example.md` is the schema doc that gets seeded into vaults and read by the compile prompt as `${agents_md}`. Currently its People + Project article-format sections describe a flat shape that contradicts the new Instruction 3 in `prompts/compile_main.md`. T02 brings the schema doc into agreement with the compile prompt:

- **People Articles** section: example block shows the two-layer page (executive summary blockquote, `## State`, `## Action Items` in Obsidian-Tasks syntax, `## Open Threads`, `## What they're building` body, `## See also`, then `---`, then `## Timeline`). Frontmatter shows the `type: person` field and `compiled_from:` list. Rules section is short — defers to `prompts/compile_main.md` for the canonical contract.
- **Project Articles** section: same two-layer shape with project-relevant State fields (`Status`, `Stack`, `Owner`), a body section, optional `## Key Decisions`, then `---`, then `## Timeline`.

No new template files needed — `templates/AGENTS.example.md` IS the canonical schema reference. Concrete per-vault page templates under `templates/knowledge/people/` / `templates/knowledge/projects/` are out of scope (would add seed-confusion; the schema doc + compile prompt are enough for the LLM to emit the right shape).
