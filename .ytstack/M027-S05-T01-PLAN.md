## What this does

1. **`as_of:` date line.** `_render_answer` derives
   `datetime.fromtimestamp(answer.as_of_mtime, tz=timezone.utc)
   .strftime("%Y-%m-%d")` → `as_of: 2026-06-10`. compile_main's generic
   frontmatter handling carries it into provenance the same way it does
   `processed_at`; exit criterion #6's "with as-of dates" becomes
   readable in both the artifact and anything compile quotes from it.
2. **Selection pin** (integration test): after a successful backend run
   on the fixture vault, `core.utils.list_raw_files()` (with its module
   path constants monkeypatched onto the tmp vault) returns the
   `raw/notes/folder/answer-*.md` artifact.
3. **Routing-parity pin** (integration test): `decide_route` on the real
   persisted answer returns `Compile`, and its
   `(substrate_prompt, model_id)` equal those of an email deep-scan
   fixture (`raw/notes/email/deep-x.md`, `type: note`) — folder answers
   ride the proven email-deep-scan lane; if anyone ever gives notes a
   dedicated dispatch, this test forces a conscious folder decision.

No engine dispatch changes, no config, no migration. The lxw e2e
(folder answer → knowledge/ article → `wiki query` returns it) is T03's
exit-criterion run.
