# M030-S01-T03 -- Task Plan

**Summary:** Description sourcing: per-article `description` (required, non-empty, ≤1024 by contract) from the article's `knowledge/index.md` summary row, falling back to the first body paragraph, finally the article stem.

## Files

- Create: `scripts/publish/describe.py`
- Create: `tests/test_publish_describe.py`

## What this does

- `description_index(index_text, knowledge_dir, vault) -> dict[rel, summary]`: parses full-index rows (`| Article | Summary | Compiled From | Updated |`) with the pipe-sentinel split for `\|` (same technique as `read_wiki_index_compact`, utils.py:193-208); the Article cell's wikilink target is cleaned via `core.links.link_target` and resolved (source = `knowledge/index.md`) to a knowledge-relative path.
- `describe(rel, body, index) -> str`: index summary if non-empty, else first non-heading paragraph of the body (frontmatter stripped via `core.frontmatter.parse` — the single frontmatter grammar), else the article stem. Wikilink markup in the chosen text collapses to alias-or-target text (reuses `publish.render` degradation idea via `WIKILINK_RE`); whitespace collapsed; hard cap 1024 (truncate to 1023 + ellipsis).
