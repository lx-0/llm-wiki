# M033-S01-T01 -- Task Plan

**Summary:** Behaviour oracle: a shared fixture vault builder in `tests/` (deterministic: a handful of knowledge articles with frontmatter, `index.md`, `state/`, `.wiki/config.yaml`) and a snapshot test that runs `menu_context` (`wiki menu --json`), `doctor --quick --json` and `cli.py help` in-process, normalises volatile fields (timestamps, version, paths) and compares to committed golden files; golden files regenerated only via an explicit `--snapshot-update` flag.

## Files

- Create: `tests/_oracle.py` — `build_fixture_vault(tmp_path)` (knowledge articles across types with frontmatter, `index.md`, `raw/requests`, `inbox/`, `daily/`, `.wiki/state/state.json`, `.wiki/logs/`, `.wiki/config.yaml` from `config.example.yaml`), `patch_engine_paths(monkeypatch, vault)` (the consumer modules' constants: `menu_context`, `core.health`, plus `HOME` / `PATH` / auth env so every quick check is machine-independent), `normalise(payload)` (numbers → `N`, ISO timestamps → `<TS>`, the vault path → `<VAULT>`, semantic version → `<VER>`), `assert_matches_golden(name, text, request)` honouring `--snapshot-update`.
- Create: `tests/test_oracle_payloads.py` — three snapshot tests (`menu --json` payload via `menu_context` in-process, `doctor --quick --json` via `core.health.build_health(quick=True)` + `doctor.render_json`, `cli.render_help()`), one test proving the comparer reports a one-word title change (the guard seen failing), one test that the goldens are in sync with the committed payload producers (fails with the update hint when missing).
- Create: `tests/golden/oracle/menu.json`, `tests/golden/oracle/doctor-quick.json`, `tests/golden/oracle/help.txt` — generated by `--snapshot-update`, reviewed by eye once.
- Modify: `tests/conftest.py` — `pytest_addoption(--snapshot-update)`.
- Modify: `docs/PROCESS.md` §18 table — one row for the behaviour oracle (cadence: every test run; catches: payload / wording drift of the operator surfaces).

## What this does

The oracle freezes the three operator-facing outputs the later refactors must not change. `build_fixture_vault` writes a small vault under `tmp_path`; `patch_engine_paths` points the modules that read the vault (`menu_context` constants, `core.health` constants — patched on the consumer module, per KNOWLEDGE "test isolation for module-level constants") at it and pins the environment the quick checks look at (`HOME` → tmp so `~/.claude/settings.json` and credentials are absent, `PATH` → a dir containing a fake `wiki`, `ANTHROPIC_API_KEY` unset). Each test produces the payload in-process, normalises it (so file ages, counts that depend on the clock, the engine version and tmp paths cannot flap) and compares the pretty-printed JSON / text to `tests/golden/oracle/<name>`; a mismatch prints a unified diff and the hint `uv run pytest tests/test_oracle_payloads.py --snapshot-update`; with the flag the golden is rewritten instead. A refactor slice is "byte-identical" when this file runs green without `--snapshot-update`; an intentional wording change updates the golden in the same commit, which makes the change visible in the diff.
