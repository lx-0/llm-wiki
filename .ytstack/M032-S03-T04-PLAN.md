# M032-S03-T04 -- Task Plan

**Summary:** Dead CSS out + a mechanical layout gate: the stylesheet blocks for the four windows now built in Svelte are deleted from `index.css`; the harness gains a DOM audit (text overflow + text-on-text overlap, the PNG gates from CLAUDE.md applied to live DOM) that runs on every capture and fails the run on overlap; the four Svelte windows pass it in light and dark.

## Files

- Modify: `desktop/src/index.css` — the Triage, Settings, Onboarding and Browse blocks (and their badge/chip/switch helpers that nothing else references) removed; what stays serves `index.html` / `renderer.ts` / `cockpit.*` / `atlas.*` until S04/S05 delete those too.
- Create: `desktop/scripts/shots/audit.cjs` — the page-side script (string) that walks text-bearing elements, reports (a) clipped text (`scrollWidth > clientWidth + 1` with hidden overflow or `nowrap`), (b) pairwise bounding-box overlaps > 100 px² between text leaves that are not ancestor/descendant, (c) elements extending past the viewport width.
- Modify: `desktop/scripts/shots/capture.cjs` — run the audit after each capture; `report.json` gains `layout: { [file]: { clipped, overlaps, offscreen } }`; any overlap fails the run (clipped text is reported, and fails only for the Svelte windows — the old panel intentionally truncates its path).

## What this does

Closes S03. The CSS deletion is a consumer-grep exercise (CLAUDE.md "unused only after a
repo-wide grep"): every class in a candidate block is checked against the surviving sources before
the block goes. The audit turns the three PNG gates into something the harness enforces on every
run instead of a reviewer's eye: overlap is the defect class that reads as "broken" to the
operator, clipping is the one that hides information. Thresholds mirror the infographic rule
(>100 px² overlap fails).
