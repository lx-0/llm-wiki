## What this does

The lint functions T01 + T02 today have no test coverage — they ran clean on the engine repo because `knowledge/` is empty there. T03 closes that gap with two-layer fixtures that exercise each warning/error path.

Approach: the test uses pytest's `monkeypatch` to point `lint.KNOWLEDGE_DIR` at a temporary directory built from the broken fixtures, drives `check_two_layer_pages()` and `check_action_item_syntax()`, and asserts the right `check` codes are present in the returned issue list. Symmetric tests on the valid fixtures (`tests/fixtures/two_layer/`) assert zero issues.

The broken-case fixtures stay separate from the valid ones because S02-T01 README pledged "lint MUST pass on every file in `tests/fixtures/two_layer/`" — broken fixtures would break that contract.
