## What this does

The fixture is a small, hand-crafted jamie transcript that contains:

- Two attendees: operator + Jane Doe
- Three commitments:
  1. **Jane → operator**: "I'll send the Q3 deck by next Friday" — owner: Jane, deadline: 2026-04-22
  2. **Operator → group**: "I'll set up the Bob intro" — first-person, lands on project page
  3. **Blocked**: "We're waiting on the infra-capacity decision from Hetzner" — open thread, not action item
- One non-commitment mention (rhetorical question or hypothetical) so the test can verify the LLM rule's "don't extract idle mentions" guidance is signal-aware

The pytest is **plumbing**, not emission:

- Asserts the fixture exists and its relative path is under `raw/transcripts/jamie/`
- Renders the compile prompt with the fixture as `source_content` and `source_path`
- Asserts the rendered prompt contains both the extraction-rule headline AND the unmodified fixture body (so the LLM sees both)
- Asserts the fixture contains the canonical commitment markers we expect the LLM to find (used later by T05 to spot-check whether the LLM caught them)

LLM-emission validation is T05's job. T04 ships the harness.
