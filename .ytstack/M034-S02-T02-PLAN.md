# M034-S02-T02 -- Task Plan

over `core.config`:
- `get KEY` / `set KEY VALUE` / `keys` / `path`, with the bash's argument-count checks;
- `status`: the summary rows and the Ollama probe;
- `help`;

the wizard). `wiki status` calls `wiki config status` through the entry, so `config_cmd_status`
leaves bash now.

## What this does

- **Parity is the oracle.** These goldens must not move: `config-get` / `keys` / `path` /
  `status` / `set` / `unknown` / `help`, the new ones, and `status`, which now calls
  `config status` through the entry.
- **Decided differences,** each taken into its golden in the port commit:
  - prompts on stderr (`Pick a key …`, `Set KEY [current: …]:`), as T01 decided;
  - error lines in the dispatcher style (`wiki: usage: …` / `wiki: unknown: …`);
  - the two corrected help lines.
- **The Ollama probe** keeps bash's contract: `GET {url}/api/tags` with a 3 s timeout, on the
  engine's `httpx`. Reachable → `✓ Ollama reachable`, otherwise
  `! Ollama unreachable at URL`, both on stdout as before.
