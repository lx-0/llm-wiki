# M034-S03-T07 -- Task Plan

**Summary:** Delete what S03 ported:
- `lib/agents.sh`, `lib/hooks.sh`, `lib/skills.sh`, `lib/config.sh`;
- the helpers they leave without a caller: `ui.sh`'s `select_one` / `select_many`, and
  `common.sh`'s `backup_file`, `HOOKS_DIR` and the `HOOK_SESSION_*` / `HOOK_PRE_COMPACT_*`
  constants. Each one is checked by a repo-wide grep before it goes.

No operator-visible change, so no release.

**Record first, then delete.** Four test files still compare Python with the bash at run
time. The bash's output is recorded as goldens, committed and pushed while the bash still
exists; the tests then compare Python with the record:
- `tests/test_agents_registry.py`: the 12 payloads (4 agents × plain / iCloud / apostrophe
  vault) go to `tests/golden/agents/payload-*.json`. The grammar cases become inline
  expectations, which are the bash probe's answers.
- `tests/test_agents_merge.py`: each merge and uninstall-after-merge text goes to
  `tests/golden/agents/{merge,uninstall}-*.json`, including the emptied-group cases.
- `tests/test_hooks_merge.py` is deleted. Every case has a Python counterpart:
  - merge / uninstall in `test_agents_merge`;
  - unreadable configs and the round trip in `test_hooks_cli`;
  - the same-second backup in `test_backup`.
- `tests/test_engine_env_location.py` keeps the `common.sh` cloud-rule tests. The two that
  sourced `lib/agents.sh` become end to end, through the real `wiki`:
  - `wiki hooks install` in a fixture vault under `…/Library/Mobile Documents/…` writes
    commands carrying `UV_PROJECT_ENVIRONMENT='<HOME>/.venvs/<vault>-wiki'` (the bash rule
    → the env → the Python payload);
  - the apostrophe-vault hook command, built by `core.agents.hook_cmd`, runs under `sh -c`.
