# M034-S05-T06 -- Task Plan

**Summary:** The operator path, end to end, on a scratch vault that starts at the real 0.7.3
tree. It covers the update to the S05 head, then every way the operator reaches the engine:
the desktop app's spawns, the Obsidian buttons, the shortcut symlink, `wiki setup` on a
fresh vault, and one compile. The findings are recorded, and a defect found on the way is
fixed (with a test and a release), not listed.

## Files

- Create: `/tmp/m034-scratch-operator.sh`, the driver (not committed). Its setup:
  - a sandboxed HOME, real uv behind a logging wrapper, the real uv cache;
  - the vault in an iCloud-shaped path, so the out-of-vault environment is on the path;
  - read-only toward the live lxw vault, nothing outside /tmp written.
- Modify: `.ytstack/M034-S05-T06-SUMMARY.md` (the findings), and `.ytstack/KNOWLEDGE.md`
  where a finding is a lesson.
- If a defect turns up: the code, a test watched failing, `CHANGELOG.md`, `pyproject.toml`,
  `uv.lock`.

## What this does

1. **Update.** A vault on `ee690a0` (0.7.3) runs `wiki update` through its own bash to
   `origin/main`. Expected: exit 0, the Python phase 2, the environment at
   `~/.venvs/<vault>-wiki`.
2. **The desktop's spawns** (`desktop/src/vault/*.ts`), run as the app runs them:
   `<vault>/.wiki/wiki <args>` with its augmented PATH, no TTY, stdin closed. That is
   `menu --json`, `doctor --json`, `query "<q>" --brief --json`, `collect --list --json`,
   `triage --list --json`, and `update` again (a no-op now). Every payload must parse, and
   every exit code must be what the app expects.
3. **The Obsidian buttons.** Each shell command the seeded Shell commands plugin carries
   (`data.json`) runs as the plugin would: its command string with the vault path in
   place, through `/bin/sh -c`. The LLM-cost ones go to step 6.
4. **The shortcut:** `wiki install-shortcut`, then `~/.local/bin/wiki version` from another
   directory.
5. **Setup on a fresh vault:** `install.sh` into a new directory, then `wiki setup` with
   piped answers (six defaults, hooks yes → claude, user scope). `wiki status` then shows
   the hooks, whose commands carry the environment.
6. **One compile:** `wiki compile --file <one raw note>` with the sandboxed HOME, if the
   Claude CLI authenticates there. If it cannot, that is a finding, and the step is reported
   blocked, not taken around the sandbox.
