## What this does

One test, the full real chain with the REAL ClaudeSdkProvider (only
paths/config monkeypatched onto tmp_path — no vault, no lxw):

1. Plant a small real trove file with two facts: a TARGET fact
   ("Die Vertragsnummer lautet KX-4711-2024.") and a RAW-BODY marker
   paragraph that a distillation must not copy (long unique lorem
   string).
2. Write a pending `folder-deep-scan` request naming that file
   (topic: "Vertragsnummer des Mobilfunkvertrags").
3. `cli._dispatch(request, dry_run=False)` — real provider, real SDK,
   real path-scope hook.
4. Assert:
   - answer artifact exists under the tmp `raw/notes/folder/` with
     `kind: folder-deep-scan` + `as_of_mtime` == the file's mtime,
   - the answer CAPTURES the fact (`"KX-4711-2024"` in body),
   - **P2 live:** the raw-body marker string appears in NO file under
     the tmp vault root,
   - request flipped to `done` with `output`.
   (Soft expectations on phrasing — assert the literal contract values
   only; LLM wording is free.)

Gating: `@pytest.mark.skipif(not os.environ.get("LLM_WIKI_LIVE_E2E"), …)`
— same machine-auth as compile (bundled CLI), no extra creds. Generous
timeout via the provider's own discipline.
