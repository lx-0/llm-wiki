## What this does

`_scan_candidates(terms, roots)` reads each `.md` once (files outer, terms inner —
not O(terms·files) re-scans), skips `index.md`, and classifies: a file whose
title/H1/slug contains a term is "primary" (→ supersede, or delete-eligible);
body-only hits are "mention" (→ edit). Returns `[{path, action, primary}]`.

The `dry_run` block additionally logs the candidate list + counts and whether
deletion is permitted for this fact (`_deletion_allowed(fm, allow_delete)`), so an
over-broad term shows up as a large candidate list before any spend. No agent.
