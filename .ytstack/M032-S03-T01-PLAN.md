## What this does

The design system the rest of the milestone builds on, derived from something real (the macOS
platform the app lives in) instead of pasted Tailwind values:

- **Neutrals with a cool hue bias** (OKLCH, hue 250) so they agree with the one accent, the
  system blue (`#007aff` light / `#0a84ff` dark). Light-mode borders are alpha
  (`rgba(0,0,0,.08)`), dark-mode borders solid; dark mode keeps the layering order (elevated =
  brightest). No pure grey anywhere.
- **Semantic colours**: ok / warn / danger from the macOS system palette, desaturated for dark.
- **Type palette** for the eight entity kinds as an OKLCH hue wheel at one lightness/chroma per
  scheme (`--type-person` … `--type-note`), the single source for badges, dots, edges and —
  later — the Overview charts. `lib/types.ts` keeps feeding the two canvases until S05 deletes
  them with Cockpit/Atlas.
- **Scales**: space 4/8/12/16/24/32, radius 6/10/14 (nested = outer − padding), type 11/12/13/15/20
  with weights 400/500/600 only, `tabular-nums` for numbers, tracking +0.06em on the few
  uppercase labels.
- **Motion**: 150 ms ease-out transitions on listed properties only; reduced-motion honoured.
- **Materials**: windows are solid `--bg`; only the panel keeps the native vibrancy (OS material,
  not CSS blur) with alpha card tokens scoped to `body.panel`.

Costume off means: no radial-gradient glow, no `backdrop-filter`, no letter-spaced monospace HUD
labels, no emoji icons, no sparkles — the primitives give every later window one Button
hierarchy (one primary per view), one Switch, one badge token.
