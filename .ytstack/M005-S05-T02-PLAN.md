## What this does

Two new counter functions:

- `count_open_commitments(KNOWLEDGE_DIR)` -- iterate `knowledge/people/*.md` + `knowledge/projects/*.md`, locate each `## Action Items` section, count non-empty lines starting with `- [ ]` (case-sensitive — `- [x]` excluded; the operator already closed those).
- `count_entities_with_action_items(KNOWLEDGE_DIR)` -- count files in the same scope that have at least one open `- [ ]` line in their Action Items section.

Both reported in callout as a single paired sentence: `📌 **Open commitments:** N across M entities`. When N == 0: `📌 **Commitments inbox:** empty — first jamie/gmeet compile will populate this from meeting substrates.` (positive framing: ready, not negative).

Frontmatter keys: `open_commitments`, `entities_with_action_items`. Available for Dataview to bind into the dashboard stat-card layout.
