## What this does

`CompileOutcome` in `types.py` (next to `CompileResult`/`CompileMetadata`):

```python
@dataclass(frozen=True)
class CompileOutcome:
    status: Literal["compiled", "skipped", "failed"]
    skip_reason: str | None = None
    failure_kind: str | None = None
    failure_detail: str | None = None
    ingest_hash: bool = False   # main() persists state[ingested][rel]=hash iff True
    cost_usd: float = 0.0
    input_tokens: int = 0
    output_tokens: int = 0
```

`Route` union in `route.py` (frozen dataclasses; `Route = Skip | IndexOnly | HealthStub | Compile`):

```python
from .types import CompileMetadata
from .classify import ClassifyResult

@dataclass(frozen=True)
class Skip:        reason: str
@dataclass(frozen=True)
class IndexOnly:   title: str; wikilinks: tuple[str, ...]
@dataclass(frozen=True)
class HealthStub:  pass
@dataclass(frozen=True)
class Compile:     metadata: CompileMetadata; classification: ClassifyResult
```

(Exact field punctuation per PEP8 in the real file — one field per line.) `IndexOnly`
carries `wikilinks` as a tuple so the dataclass stays hashable/frozen-clean; the
handler that builds the index entry (S03) gets the `source` Path separately.

No `decide_route()` yet — S02 implements it and returns these.
