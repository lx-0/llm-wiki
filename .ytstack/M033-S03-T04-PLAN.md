## What this does

One look for every CLI (the colored, TTY-aware `ConsoleFormatter` that compile has had since
2026-05-15: INFO label hidden, ✓/✗ colored, no timestamp on stderr; file archives keep ISO
timestamps), one idempotent setup that can be called from any entry without stacking
handlers, and no logging configured at import time anywhere — importing an engine module
never touches the root logger again. What changes for the operator: stderr lines of the
migrated CLIs lose the `2026-10-14T20:24:56  INFO  ` prefix and gain compile's colors; the
`logs/*.log` archives keep timestamps. stderr parity: `wiki collect --list`, `wiki preprocess
--list`, `wiki review-wiki --dry-run`, `wiki doctor --quick` captured before and after; the
oracle (`menu --json`, `doctor --json`, `help`) must be byte-identical — none of it writes
through logging.
