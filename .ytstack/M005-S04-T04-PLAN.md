## What this does

Closes the lifecycle-fixture test pattern with the negative case: when substrate touches a page but doesn't carry resolution evidence for an existing `[x]`, the compile pass should NOT auto-demote the `[x]`. The operator's checkmark stays in State.

The `## Expected lifecycle outcome` block on the AFTER substrate encodes:
- **PRESERVE**: `- [x] Sign the contract` stays in State (operator-owned).
- **NEW Timeline entry**: append `- **YYYY-MM-DD** | <substrate> — <summary>` for the substrate touch.
- **NO demotion**: even though substrate touched the page, no `[resolved]` is added — preservation is not the same as resolution.

This is the rule from T01 ("Preserve manual `- [x]`") — T04 documents the behavior in fixture form so the canary runbook (and future operator iterations) have something concrete to test against.
