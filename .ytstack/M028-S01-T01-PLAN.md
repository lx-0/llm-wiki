## What this does

Replace the `ClaudeAgentOptions(...)` block in `apply()` (currently L122-131):

- `allowed_tools`: `["Read", "Write", "Edit", "Glob", "Grep", "Bash"]`
  → `["Read", "Glob", "Grep", "Write", "Edit"]` (Bash removed).
- Add `hooks={"PreToolUse": [HookMatcher(matcher="Write|Edit",
  hooks=[make_path_scope_hook([KNOWLEDGE_DIR, DAILY_DIR, INDEX_FILE, LOG_FILE])])]}`.
  Import `KNOWLEDGE_DIR, DAILY_DIR, INDEX_FILE` from `core.paths` (LOG_FILE already
  imported). Mirrors `reconcile_fact()` L240-247.
- `permission_mode`: `"acceptEdits"` → `"default"`.
- `max_turns`: `50` → `CONFIG.limits.correct_apply_max_turns`.
- Keep `max_buffer_size`, `cwd`, `model`, `system_prompt`, `stderr` unchanged.

Extract into a module-level helper so it is testable:

```python
def _apply_agent_options(capture) -> ClaudeAgentOptions:
    return ClaudeAgentOptions(
        max_buffer_size=CONFIG.limits.sdk_max_buffer_size_mb * 1024 * 1024,
        cwd=str(ROOT_DIR),
        model=CONFIG.models.compile_model,
        allowed_tools=["Read", "Glob", "Grep", "Write", "Edit"],
        hooks={"PreToolUse": [HookMatcher(
            matcher="Write|Edit",
            hooks=[make_path_scope_hook(
                [KNOWLEDGE_DIR, DAILY_DIR, INDEX_FILE, LOG_FILE])],
        )]},
        permission_mode="default",
        max_turns=CONFIG.limits.correct_apply_max_turns,
        system_prompt={"type": "preset", "preset": "claude_code"},
        stderr=capture.callback,
    )
```

`apply()` calls `options=_apply_agent_options(capture)` inside the `query(...)`.

**Scope note (T02 dependency):** T01 scopes writes to `[KNOWLEDGE_DIR, DAILY_DIR,
INDEX_FILE, LOG_FILE]`. Because `make_path_scope_hook` is allow-list-only today,
`knowledge/facts/` is still writable in the T01-only state — the prompt forbids
it, and **T02** adds the `denied_subpaths=[FACTS_DIR]` exclusion that closes it.
Both land before S01 closes. Do not claim facts/-protection done until T02.
