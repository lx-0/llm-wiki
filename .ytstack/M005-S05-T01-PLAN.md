## What this does

The existing `## ✅ Open tasks` section aggregates `- [ ]` checkboxes from working files only, explicitly excluding `knowledge/`. M005 changes that calculus: `knowledge/people/` and `knowledge/projects/` now legitimately carry the operator's commitments. The new `## 📌 Personal Tasks (Wiki)` section is the entity-page-focused inbox.

Three Tasks-plugin query blocks under the new heading:

1. **🔥 Overdue** — `not done` + `due before today` + `path includes knowledge/people` OR `path includes knowledge/projects`. Sort by due date. Limit 20.
2. **⚡ Today** — `not done` + `due on today` + same path filters. Sort by priority.
3. **🗓 This week** — `not done` + `due after today and before today+7d` + same path filters. Sort by due date.

Plus an "all open" fallback for items without due dates so they don't fall off the dashboard.

The section sits between `## ✅ Open tasks` and the existing engine-side stuff so the visual flow is "engine-internal lint" → "vault working files" → "wiki entity commitments" → "browse knowledge".
