# New helper (sibling to _frontmatter_type, ~10 LOC regex)
def _frontmatter_compile_role(content: str) -> str | None:
    if not content.startswith("---"):
        return None
    end = content.find("\n---", 3)
    if end == -1:
        return None
    block = content[3:end]
    m = re.search(r"^compile_role:\s*[\"']?([\w-]+)[\"']?\s*$", block, re.MULTILINE)
    return m.group(1) if m else None

**Behavior:**
- File with `compile_role: final-only` → logged as skip + returns `_skipped` (does NOT count as a failure; preserves consecutive-failure budget, like the existing `_skipped` substrate-type pattern at line 439).
- File with `compile_role: source-and-final` → falls through to current distill path (T02 changes this).
- File with `compile_role: source-only` or no frontmatter → falls through unchanged (today's behavior).
- File with invalid `compile_role:` → ValueError raised by `infer_compile_role()` (lint catches it at structural level; runtime is loud).
