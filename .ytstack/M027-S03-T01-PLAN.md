## What this does

Sibling of `maybe_generate_curiosity_requests` (email), same split-provider
posture (Ollama-only, no cloud fallback):

```
_indexed_paths(digest_text) -> set[str]
    # every backticked path in the digest's Tree + Recent sections
    # (full rel_paths after the prereq amendment); dirs included
    # (trailing / stripped for matching).

_load_folder_digests(budget_chars) -> (digest_block, {root_id: set[paths]})
    # reads raw/index/*.md; returns "" when none exist. Consumer-side
    # budget (DECISIONS 2026-06-10): full digests if they fit
    # budget_chars; else per-root trim — drop file lines from Tree,
    # keep dir skeleton + Recent section, log INFO with what was
    # trimmed (no silent caps).

async def maybe_generate_folder_requests(source: Path) -> None:
    # Gates (cheap → expensive, mirroring the email pass):
    #   features.curiosity_loop · personal.watched_folders non-empty ·
    #   len(source) >= curiosity_min_source_chars ·
    #   curiosity_source_globs match · digests exist (else INFO-skip) ·
    #   ollama_client.is_reachable()
    # Prompt: render("compile_curiosity_folder", source_path,
    #   source_content=5k excerpt, folder_digests=digest_block,
    #   timestamp) — template ships in T02; tests stub render().
    # Schema: gaps[] of {topic, root_id (enum of watched root ids),
    #   file_path (string), file_confidence (1-5), rationale}.
    # Validation per gap (drop-counter dict like email):
    #   - topic/rationale non-empty
    #   - file_confidence int >= curiosity_folder_confidence_min
    #     (REUSED knob — same semantics: abstain over guessing)
    #   - FILE-EXISTS ANCHOR: file_path ∈ indexed paths of root_id
    #     (invented/hallucinated path -> dropped["file_not_indexed"]) —
    #     this replaces source_quote: the index IS what the model saw,
    #     so membership = verifiable anchoring
    #   - duplicate request file / _slug_previously_rejected (reused)
    # Request JSON (raw/requests/request-<slug>-<date>.json):
    #   {type: "folder-deep-scan", status: "pending", root_id,
    #    file_path, file_confidence, topic, rationale,
    #    source: <rel source path>, model, created}
```

Error handling mirrors the email pass verbatim (timeout / 404-model-hint /
HTTP / parse / catch-all — WARNING, never raise).

Tests (~6):

1. render: tree lines carry full rel_paths (existing tests amended).
2. happy path: mocked chat_schema returns a gap naming an indexed path →
   request JSON written with `type: folder-deep-scan` + anchor fields.
3. invented path → dropped (`file_not_indexed`), no request file.
4. `file_confidence` below threshold → dropped.
5. no watched_folders / no digests → returns before any LLM call
   (chat_schema mock asserts not-called).
6. over-budget digests → trimmed block still contains dir skeleton +
   Recent lines, prompt render receives < budget chars.
