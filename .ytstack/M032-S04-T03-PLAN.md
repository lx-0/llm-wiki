## What this does

Principle 2 (one action, one place, one verb): `nextUp()` is the only list of things to do.
Doctor-fixable issues come first by severity, then the engine's counted suggestions in its
group order; tools never appear here — they live in the footer's Tools sheet, so a quiet vault
shows an empty Next-up ("Nothing to do") instead of five idle buttons. Each row is title + verb
button; when its argv is running the button becomes an inline progress bar ("3 of 12" or
indeterminate); when it finished, a done / failed pill stays until the panel closes
(`panel.run.results`). Recent keeps the five newest entries with the type badge and a dot on
entries newer than the last time the panel was open. The footer collapses the three rarely-used
things into one row: `+ Add link` opens the input inline (YouTube → ingest-youtube, http(s) →
ingest-html, else "Paste a web page or YouTube link"), Sources opens a sheet with one row per
configured collector (Sync) and a Sync all that queues them, Tools opens the engine tools; Quit
stays at the right. No section hints, no provenance paragraph, no emoji.

Height budget at rest: header 72 + ask 36 + strip 84 + next-up (≤ 5 × 36 + 22) + recent (5 × 30
+ 22) + footer 28 + gaps ≈ 600 px — measured by the harness; T04 trims if it lands above 640.
