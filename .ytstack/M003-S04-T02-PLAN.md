## What this does

Three Markdown stubs, each ~10 lines: frontmatter + H1 + 2-line description + a Dataview LIST query that auto-pulls the relevant knowledge folder. Operator opens any stub, sees the auto-list, can hand-curate by adding wikilinks above the dataview block.

`_seed_file` is additive (preserves existing files), so re-running `wiki seed` on a vault with hand-curated MOCs leaves them untouched. `--force` overwrites — operator's responsibility.
