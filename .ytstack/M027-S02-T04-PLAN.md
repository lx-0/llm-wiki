## What this does

```
main(argv) -> int      # in folder_index.py, `wiki index` shells here

wiki index                  # sync every kind=local watched_folders entry
wiki index <root-id>        # sync exactly one entry (unknown id -> error, exit 1)
wiki index --force          # bypass delta-skip (re-write all digests)
```

Behaviour:

- Reads `CONFIG.personal.watched_folders`; no entries (or none `kind=local`)
  → friendly hint ("configure personal.watched_folders") + exit 0.
- Per local entry: `sync_root(entry, max_depth=CONFIG.limits.
  folder_index_max_depth, recent_n=…_recent_n, max_tree_entries=
  …_max_tree_entries, force=args.force)`; prints one line per root
  (`written <path>` / `unchanged — skipped`).
- `kind=smb` entries: logged INFO "skipped (NAS lands in S06)" — not an
  error.
- A root that raises `ValueError` (nonexistent path) or unexpected OSError:
  WARNING + continue with the other roots (fail-soft, collector posture);
  exit 1 only if at least one root failed, else 0.
- `wiki` dispatcher: `cmd_index()` runs
  `"$PY" "$SCRIPTS_DIR/collectors/folder_index.py" "$@"` (match the repo's
  existing shell-out convention for script verbs); help text documents the
  three knobs + S06 NAS deferral.
- Knob lifting per plan-rule from T01: defaults live in `Limits`, the
  example yaml documents them, KEY_ADDITIONS injects them into operator
  vaults (migration same commit).

Tests (~4, monkeypatch `CONFIG.personal.watched_folders` + `INDEX_DIR` +
`STATE_FILE` onto tmp_path):

1. `main([])` syncs all local entries (digest files exist), skips smb
   entry without failing, returns 0; second run reports unchanged (delta
   path through the CLI).
2. `main(["<root-id>"])` syncs only that entry; unknown id → exit 1.
3. `main(["--force"])` re-writes an unchanged tree.
4. failing root (nonexistent path) → other roots still synced, exit 1.

Plus migration: round-trip change-count bump + 3 new keys asserted
(reuse existing assert style; no standalone reflex test fns).
