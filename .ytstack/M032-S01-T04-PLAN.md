## What this does

Forge 8 (2026-09-29): ESM-only packages on Node ≥ 22.17 (local Node 24.18 ✓), Vite plugin stable
and pinned to Vite 8, main + preload bundles emitted as `.cjs` (the plugin stops with an error if
`package.json#main` or the preload path still say `.js`), DMG output moves to
`out/make/dmg/<arch>/` (the reinstall script finds the `.app` under `out/` with `maxdepth 2` —
unaffected), `electron-forge publish` → `release` (unused here), `@electron/fuses` 2 required by
plugin-fuses. Vite 8 is Rolldown-based; vitest 4 (peer `vite ^6||^7||^8`) then shares the app's
Vite instead of nesting its own copy. Steps: bump the nine Forge packages + fuses + vite in one
`npm install`; point `main` at `main.cjs` and the seven preload paths at `preload.cjs`; run
`npm run package` (full Forge pipeline: three Vite builds + packager — proves the config loader,
the plugin and the fuses flip on the new majors) and `npm run shots` (standalone renderer build on
Vite 8 + the harness) and `npm test`; fix whatever the migration guide or the compilers flag.
