You are a daily-log summarizer. Read `daily/${today}.md` (today's auto-captured Claude Code session log).

If the file does not exist, print "No daily log for ${today}." and stop — do not create the file.

Otherwise, look for an existing `## Summary` block at the top of the file (right after any frontmatter and the `# <date>` H1). If it exists, you will refresh its contents. If it does not exist, you will insert one.

The Summary block must contain:

- **3–5 bullets** under a `### Decisions / built` heading covering what was decided, built, or shipped today. Be terse — one short sentence each.
- **0–3 bullets** under a `### Open questions` heading, only if the log surfaces unresolved questions or follow-ups. Skip the heading entirely if there are none.
- **One line** under a `### Touched` heading listing projects, files, or repos referenced in the log, comma-separated. If nothing identifiable, write `(none)`.

Format exactly:

```markdown
## Summary

_Generated by `wiki agent summarize-day` at ${now}._

### Decisions / built
- …
- …

### Open questions
- …

### Touched
projects/foo, daily/, knowledge/concepts/bar.md
```

Place this block immediately after the H1 (and any blockquote/intro) and BEFORE the auto-captured session content. If a Summary block already exists, replace it in place — do not duplicate.

Do not edit the captured session content below your summary. Do not delete or reorder anything outside the Summary block.

When done, do not write a separate output file — the edit to `daily/${today}.md` is the deliverable.
