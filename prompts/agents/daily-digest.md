You produce **one short daily digest** from the per-source captures under `daily/${date}/`.

## Inputs

1. List the per-source capture files for the target date:

   `Glob` pattern `daily/${date}/*.md`

   Expected files (zero or more may be present):
   - `sessions.md` — Claude Code conversations of the day (verbose; the operator already lives those, the digest does NOT need to re-narrate them — pick only the few sharp moments).
   - `health.md` — Oura daily one-liner per account (sleep / readiness / HRV / steps / resting HR).
   - `meetings.md` — gmeet + jamie meeting one-liners.
   - `voice.md` — operator dictation intakes of the day.
   - `email.md` — email-delta-report links (count + per-account).

2. Read each file that exists. Skip silently if a source has no file.

## Output

Write `daily/${date}.md` (overwrites if it exists). Use this exact shape:

```markdown
---
title: "Daily — ${date}"
type: daily-digest
date: ${date}
sources: [list of source-files that existed]
---

# Daily — ${date}

_Digest of `daily/${date}/` generated by `wiki agent daily-digest` at ${now}._

## Highlights

- 3-7 bullets covering the most important moments across ALL substrate sources.
- Mix substrate types — don't dedicate the digest to just sessions. A morning HRV dip, a key 1:1, a voice-note insight, and a focused build session should all be candidates.
- Each bullet ≤ 25 words. Use [[wikilinks]] to source files where helpful.

## Physical

One short paragraph (≤ 60 words) from `health.md` if it exists. Mention only the values that surface a story (sleep length out of pattern, readiness change, HRV trend if visible from this one day). If `health.md` is absent → skip this section entirely.

## Meetings

Bullet list from `meetings.md` if any meetings happened. Format: `**HH:MM** · <title> → [[stem]]`. If no meetings → skip the section.

## Voice notes

Bullet list from `voice.md` if any. Use the existing one-liner form. If none → skip the section.

## Email

Single line from `email.md` if there was a delta-run. Skip otherwise.
```

## Rules

- **Length cap: ≤ 500 words total.** The whole point of this digest is that current daily/ files are "uebertrieben lang" — keep this tight. If you find yourself near the cap, cut Highlights bullets, not the substrate sections.
- **Do not paste verbatim from `sessions.md`.** It's the longest source and the lowest signal-per-word. Use it for "what was the day's narrative arc" — one or two bullets max in Highlights.
- **Empty days are not failures.** If only `sessions.md` exists with brief content, write a 3-bullet Highlights + skip the other sections.
- **Existing root file:** if `daily/${date}.md` already exists with a different `type:` (e.g. operator hand-edited it for some reason), STOP and print `"daily/${date}.md exists with non-digest frontmatter — refusing to overwrite operator content."` Do not write.

When done, the edit to `daily/${date}.md` is the deliverable.
