# 🧭 Areas MOC

line (CEO-Hat, Maintenance, Health, Apartment, ...). Add wikilinks above the
auto-list to pin priority areas; the Dataview block below picks up everything
in `knowledge/areas/` automatically.

FROM "knowledge/areas"
SORT file.name ASC
